# BaSYS

BaSYS (Business Applications System) — это LowCode-платформа для создания бизнес-приложений. 
Система основывается на использовании слоя метаданных, который задает структуру и логику бизнес-модели. 
Такой подход обеспечивает одновременно высокую гибкость и быструю разработку приложений.
