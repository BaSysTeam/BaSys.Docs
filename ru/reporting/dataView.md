# Панели данных (Data view)

Панель данных — это визуальный конструктор отчётов платформы **BaSYS**, позволяющий объединять на одном экране произвольное количество визуальных компонентов: графиков, диаграмм, индикаторов, таблиц и сводных таблиц. Каждый компонент привязывается к собственному источнику данных и настраивается независимо.

Данные для компонентов извлекаются из базы данных при помощи [построителя запросов](../calculations/queryBuilder.md) BaSYS и при необходимости обрабатываются с использованием [библиотеки функций](../calculations/index.md) BaSYS.

Панель данных охватывает широкий спектр задач отчётности. На одном полюсе — простейший табличный отчёт, состоящий из единственной таблицы. На другом — полноценный dashboard, включающий множество индикаторов, графиков и сводных таблиц. Промежуточные варианты: отчёт с одной сводной таблицей, диаграмма с сопроводительной таблицей данных и т.д. Панель данных рекомендуется как основной инструмент создания отчётов: она проста в настройке и не требует программирования.

## Размещение визуальных компонентов

Расположение компонентов на экране определяется 12-колоночной сеткой CSS-фреймворка PrimeFlex. Экран условно делится на 12 равных колонок, и каждый компонент занимает определённое количество этих колонок.

Положение компонента задаётся двумя параметрами:

- **Ширина** — количество колонок, которое занимает компонент.
- **Отступ слева** *(необязательный)* — количество пустых колонок перед компонентом.

Компоненты выстраиваются последовательно: каждый следующий компонент размещается правее предыдущего в текущей строке. Если суммарная ширина (включая отступы) превышает 12 колонок, компонент автоматически переносится на новую строку.

### Предустановленные размеры

Для удобства настройки доступны предустановленные значения ширины и отступа. При выборе варианта **Custom** можно задать точное количество колонок вручную.

**Ширина (Width):**

| Значение | Колонок | Описание              |
| :------- | :------ | :-------------------- |
| Small    | 3       | Четверть строки       |
| Half     | 6       | Половина строки       |
| Wide     | 8       | Две трети строки      |
| Full     | 12      | Вся строка            |
| Custom   | 1–12    | Произвольное значение |

**Отступ слева (Offset):**

| Значение | Колонок | Описание              |
| :------- | :------ | :-------------------- |
| None     | 0       | Без отступа           |
| Small    | 3       | Четверть строки       |
| Half     | 6       | Половина строки       |
| Wide     | 8       | Две трети строки      |
| Custom   | 0–12    | Произвольное значение |

### Пример: два компонента в строке

Рассмотрим Панель данных с тремя компонентами: два индикатора значения и таблица.

| Компонент   | Ширина    | Отступ   |
| :---------- | :-------- | :------- |
| Индикатор A | Half (6)  | None (0) |
| Индикатор B | Half (6)  | None (0) |
| Таблица C   | Full (12) | None (0) |

Индикатор A занимает 6 колонок. Индикатор B тоже занимает 6 колонок — в сумме 12, поэтому оба помещаются в одну строку. Таблица C требует 12 колонок и переносится на следующую строку:

```
Строка 1: [ Индикатор A (6 кол.) ][ Индикатор B (6 кол.) ]
Строка 2: [              Таблица C (12 кол.)               ]
```

### Пример: использование отступа

Отступ позволяет сместить компонент вправо, оставив часть строки пустой.

| Компонент   | Ширина    | Отступ    |
| :---------- | :-------- | :-------- |
| Индикатор A | Half (6)  | Small (3) |
| График B    | Full (12) | None (0)  |

Индикатор A имеет отступ 3 колонки и ширину 6 колонок — итого занимает 9 колонок из 12. Оставшиеся 3 колонки строки остаются пустыми. График B переносится на следующую строку:

```
Строка 1: [пусто (3)][ Индикатор A (6 кол.) ][пусто (3)]
Строка 2: [              График B (12 кол.)              ]
```

### Высота и порядок

Помимо ширины и отступа, для каждого компонента доступны:

- **Высота** — задаёт фиксированную высоту компонента с указанием единиц измерения (например, `400px`, `25rem`). Если не задана, высота определяется автоматически по содержимому.

## Визуальные компоненты

### Общие настройки

Все визуальные компоненты имеют набор общих настроек:

- **Заголовок (title)** — Заголовок компонента, отображаемый в панели. Необязательный — если не задан, заголовок не выводится. Это удобно, например, для панели данных с единственной таблицей.
- **Имя (name)** — Человекочитаемый идентификатор компонента.
- **Примечание (memo)** — Произвольная текстовая информация.
- **Источник данных (dataSource)** — Источник данных, на основе которого компонент формирует визуализацию.
- **Активен (isActive)** — Если включено, компонент отображается в Панели данных. Позволяет временно скрыть компонент без удаления.
- **Высота (height)** — Фиксированная высота компонента. Необходимо указывать единицы измерения: `px`, `rem` и т.д. Если не задана, компонент масштабируется автоматически.
- **Порядок (order)** — Позиция компонента в очереди отображения.
- **Ширина и отступ (renderSettings)** — Параметры размещения в 12-колоночной сетке, описанные в разделе выше.

Далее описаны доступные типы визуальных компонентов и их специфические настройки.

---

### Индикатор значения

Отображает единичное значение крупным текстом — типичное применение для ключевых показателей (KPI): выручка, количество заказов, средний чек и т.п. Компонент извлекает значение из источника данных и форматирует его в соответствии с заданным форматом.

**Настройки:**

- **Путь к данным (dataPath)** — Имя поля в объекте источника данных, значение которого будет отображено. Необходимо, если источник данных возвращает объект с несколькими полями.
- **Формат (format)** — Выражение форматирования для отображаемого значения. Для форматирования используется функция `format()` из библиотеки BaSYS.FX.
- **Цвет (colorHint)** — Цвет отображаемого значения. Доступные варианты: Primary, Secondary, Success, Info, Warning, Danger, Contrast. При выборе Custom можно задать произвольный цвет.
- **Цвет HEX (colorHex)** — Произвольный цвет значения в формате HEX без символа `#`. Пример: `00ff00`. Используется при выборе варианта Custom.

---

### Индикатор-шкала (Gauge)

Отображает значение в виде полукруговой шкалы с цветовыми зонами. Применяется для показателей, имеющих естественные пороговые значения: загрузка оборудования, выполнение плана, уровень запасов и т.п. Цветовые зоны позволяют визуально оценить, в какой области находится текущее значение.

**Настройки:**

- **Путь к данным (dataPath)** — Имя поля в объекте источника данных, значение которого отображается на шкале.
- **Формат (format)** — Выражение форматирования для отображаемого значения.
- **Минимальное значение (minValue)** — Определяет начало шкалы.
- **Уровни (levels)** — Пороговые значения шкалы. Каждый уровень задаёт верхнюю границу зоны и её цвет. Уровни определяются последовательно: первый уровень — от минимального значения до порогового значения первого уровня, второй — от первого до второго и т.д.

**Настройки уровня:**

- **Заголовок (title)** — Название зоны (например, «Норма», «Критично»).
- **Пороговое значение (levelValue)** — Верхняя граница зоны.
- **Цвет (colorHex)** — Цвет зоны в формате HEX.

---

### Гистограмма

Столбчатая диаграмма для сравнения значений по категориям. Поддерживает вертикальную и горизонтальную ориентацию, режим накопления (stacked), несколько рядов данных на одной диаграмме и настройку осей.

**Настройки:**

- **Положение легенды (legendPosition)** — Положение легенды на диаграмме: нет, сверху, слева, снизу, справа. При выборе «Нет» легенда скрывается.
- **Ориентация (orientation)** — Ориентация столбцов: вертикальная или горизонтальная.
- **Режим накопления (stacked)** — Если включено, значения рядов данных отображаются друг над другом (столбцы суммируются).
- **Колонка меток (labelsColumnName)** — Имя колонки источника данных, значения которой отображаются как подписи на оси категорий (например, названия месяцев, городов или продуктов).
- **Ось X (xAxis)** — Настройки горизонтальной оси.
- **Ось Y (yAxis)** — Настройки вертикальной оси.
- **Ряды данных (dataSets)** — Наборы данных, отображаемые на диаграмме. Каждый ряд привязан к колонке источника данных.
- **Цвета фона (backgroundColors)** — Дополнительные цвета для отдельных столбцов (по индексу).

**Настройки оси:**

- **Заголовок (title)** — Подпись оси на диаграмме.
- **Тип шкалы (scaleType)** — Тип шкалы: Category (текстовые метки), Linear (равномерные числовые значения), Logarithmic (данные с большим разбросом), Time (временные ряды).
- **Единица времени (timeUnit)** — Единица времени при типе шкалы Time.

**Настройки ряда данных:**

- **Заголовок (title)** — Название ряда, отображаемое в легенде.
- **Имя колонки (columnName)** — Имя колонки источника данных, содержащей значения ряда.
- **Цвет (colorHex)** — Цвет ряда в формате HEX.

---

### Линейный график

Визуализирует динамику и тенденции изменения данных. Поддерживает сглаживание линий, заливку области под графиком, отображение точек данных и несколько рядов данных одновременно.

**Настройки:**

- **Положение легенды (legendPosition)** — Положение легенды: нет, сверху, слева, снизу, справа.
- **Сглаживание (tension)** — Степень сглаживания линий. Значение `0` — прямые отрезки между точками данных. Значения от `0.1` до `1` — плавные кривые; чем выше значение, тем сильнее сглаживание. Рекомендуется: `0` для точного отображения, `0.3`–`0.4` для умеренного сглаживания.
- **Заливка (fill)** — Если включено, область под линией графика заливается цветом.
- **Прозрачность заливки (fillOpacity)** — Прозрачность области заливки. Допустимые значения: от `0` (полностью прозрачная) до `1` (полностью непрозрачная).
- **Радиус точек (pointRadius)** — Радиус точек данных на графике. Значение `0` скрывает точки. Допустимые значения: от `0` до `20`.
- **Колонка меток (labelsColumnName)** — Имя колонки источника данных с подписями оси категорий.
- **Ось X (xAxis)** — Настройки горизонтальной оси (аналогично гистограмме).
- **Ось Y (yAxis)** — Настройки вертикальной оси (аналогично гистограмме).
- **Ряды данных (dataSets)** — Наборы данных (аналогично гистограмме).
- **Цвета фона (backgroundColors)** — Дополнительные цвета.

---

### Круговая диаграмма

Отображает доли целого в виде секторов круга. Подходит для визуализации структуры: распределение расходов по категориям, доли рынка, состав портфеля и т.п.

**Настройки:**

- **Положение легенды (legendPosition)** — Положение легенды: нет, сверху, слева, снизу, справа.
- **Вырез (cutout)** — Процент внутреннего выреза. Значение `0` — полный круг без выреза. Допустимые значения: от `0` до `90`%.
- **Колонка меток (labelsColumnName)** — Имя колонки источника данных с названиями секторов.
- **Ряды данных (dataSets)** — Наборы данных (значения секторов).
- **Цвета фона (backgroundColors)** — Цвета секторов диаграммы.

---

### Кольцевая диаграмма

Разновидность круговой диаграммы с вырезом в центре. По настройкам полностью аналогична круговой диаграмме. Отличие — значение **Вырез (cutout)** по умолчанию равно `50`%, что создаёт кольцевой вид. Значение выреза можно изменить.

---

### Таблица

Отображает данные в табличном виде с поддержкой форматирования, закрепления колонок, вычисления итогов и виртуализации для больших объёмов данных.

**Настройки таблицы:**

- **Масштаб (size)** — Определяет размер шрифтов и отступов: Normal, Compact, Small.
- **Виртуализация (useVirtualization)** — Если включено, строки отрисовываются по мере прокрутки. Рекомендуется для больших таблиц (1000 строк и более).

Столбцы таблицы настраиваются индивидуально.

**Настройки колонки:**

- **Заголовок (title)** — Заголовок колонки в шапке таблицы.
- **Имя (name)** — Имя колонки. Должно совпадать с именем колонки в источнике данных.
- **Тип данных (columnKind)** — Тип данных: String (строка), Number (число), Date (дата), Boolean (логическое), Icon (иконка).
- **Ширина (width)** — Ширина колонки с указанием единиц измерения (например, `200px`, `10rem`). Если не задана, определяется автоматически.
- **Выравнивание (horizontalAlignment)** — Горизонтальное выравнивание текста в ячейках: Left, Center, Right.
- **Формат (format)** — Выражение форматирования значений колонки.
- **CSS-класс иконки (iconClass)** — CSS-класс иконки для колонок типа Icon. Используются иконки из библиотеки PrimeIcons.
- **Закрепление (frozen)** — Если включено, колонка закрепляется слева и не смещается при горизонтальной прокрутке.
- **Итоги (showTotals)** — Если включено, по колонке вычисляется итог. Доступно только для числовых колонок.
- **Агрегатная функция (aggregateFunction)** — Функция вычисления итога: Sum (сумма), Count (количество), Min (минимум), Max (максимум), Average (среднее).

---

### Сводная таблица

Компонент многомерного анализа данных. Позволяет группировать данные по строкам и колонкам, вычислять агрегированные значения (суммы, количества и т.д.) и представлять результат в виде перекрёстной таблицы. Поддерживает сворачивание/разворачивание групп, закрепление колонок, вычисление итогов и просмотр исходных записей внутри групп.

**Настройки сводной таблицы:**

- **Итоги по строкам (showRowTotals)** — Если включено, отображаются итоги по строкам.
- **Итоги по колонкам (showColumnTotals)** — Если включено, отображаются итоги по колонкам.
- **Закреплённые колонки (frozenColumnsColumn)** — Количество колонок группировки строк, закреплённых слева. Закреплённые колонки не смещаются при горизонтальной прокрутке. Значение `0` — нет закреплённых колонок. Детальные колонки не закрепляются; количество закреплённых колонок ограничено числом полей группировки строк.
- **Раскрытие групп по умолчанию (groupDefaultExpanding)** — Определяет, в каком состоянии отображаются группы строк при первой отрисовке: все группы свёрнуты, все раскрыты или раскрыт только первый уровень.
- **Показывать детальные записи (showDetails)** — Включает вывод каждой исходной записи отдельной строкой. По умолчанию выключено, в том числе для ранее созданных сводных таблиц.
- **Детальные поля (detailFields)** — Упорядоченный список ссылок на доступные поля, значения которых выводятся в дополнительных колонках детальных строк. По умолчанию пуст. Выключение детализации сохраняет выбранные поля и их порядок.

Структура сводной таблицы определяется набором **доступных полей**, которые назначаются в области:

- **Строки** — Поля группировки строк.
- **Колонки** — Поля группировки колонок.
- **Значения** — Показатели, для которых вычисляются агрегаты.
- **Детальные поля** — Дополнительные сведения об исходных записях, например документ, дата или комментарий. Отображаются при включённой детализации.

Поле группировки строк или колонок нельзя одновременно выбрать как детальное. При добавлении детального поля в группировку оно исключается из детальных полей. Поле показателя можно одновременно использовать в области значений и в детальных полях.

**Настройки поля:**

- **Заголовок (title)** — Заголовок поля в шапке сводной таблицы.
- **Имя (name)** — Имя поля. Должно совпадать с именем колонки в источнике данных.
- **Тип данных (kind)** — Тип данных: String (строка), Number (число), Date (дата), Boolean (логическое).
- **Ширина (width)** — Ширина колонки в таблице.
- **Выравнивание (horizontalAlignment)** — Горизонтальное выравнивание: Left, Center, Right.
- **Формат (format)** — Выражение форматирования значений.

**Настройки значения:**

Поля, помещённые в область значений, агрегируются по заданной функции.

- **Поле (fieldUid)** — Ссылка на поле из списка доступных полей.
- **Агрегатная функция (aggregateFunction)** — Функция агрегации: Sum (сумма), Count (количество), Min (минимум), Max (максимум), Average (среднее).

#### Настройка детализации

Детализацию можно настроить в конструкторе компонента или в диалоге **Настройки сводной таблицы** при просмотре панели данных:

1. Включите **Показывать детальные записи**.
2. В секции **Детальные поля** добавьте нужные поля. Поля можно удалять и перемещать вверх или вниз — их порядок определяет порядок дополнительных колонок.
3. В диалоге таблицы нажмите **Применить**. Отмена оставляет действующие настройки без изменений.

Детальные поля можно выбрать заранее при выключенном режиме. При сохранении метаобъекта в конструкторе сохраняются режим детализации, состав полей и их порядок. Изменение только состава или порядка детальных полей не сбрасывает раскрытие групп.

#### Отображение детальных записей

При включённой детализации каждая исходная запись отображается отдельной строкой внутри раскрытой последней группы строк. Совпадающие записи не объединяются; внутри группы сохраняется порядок записей источника данных. Последняя группа, как и остальные, получает возможность сворачивания. Свёрнутая группа скрывает дочерние строки и показывает агрегированные значения.

Команды **Раскрыть все** и **Свернуть все** учитывают последний уровень группировки. Начальное состояние определяется настройкой **Раскрытие групп по умолчанию**:

- **Все раскрыты (AllOpen)** — Раскрыты все уровни, включая детальные записи.
- **Все закрыты (AllClosed)** — Верхние группы свёрнуты, детальные записи скрыты.
- **Первый уровень раскрыт (FirstLevelOpen)** — Раскрыт только первый уровень. Если группировка строк одна, детальные записи видны сразу.

Если группировки строк не заданы, исходные записи выводятся непосредственно в таблице без дополнительной группы. Пустой список детальных полей не выключает детализацию: таблица продолжает показывать отдельные записи с их показателями. Если показатели не выбраны, выводятся только колонки группировки строк и детальные колонки. При пустом источнике данных детальных строк нет.

В режиме детализации записи с пустым или отсутствующим значением группировки попадают в пустую группу и участвуют в итогах.

Колонки располагаются в порядке: **группировки строк → детальные поля → показатели → итоговые колонки**. Заголовки детальных полей занимают всю высоту шапки, в том числе при многоуровневой группировке колонок. На строках групп и итогов детальные ячейки остаются пустыми.

Детальные колонки используют заголовок, ширину, выравнивание и формат соответствующего поля. Если заголовок не задан, выводится имя поля. Пустые значения отображаются пустыми ячейками, а `0` и `false` сохраняются. При ошибке форматирования выводится строковое представление исходного значения.

#### Показатели и итоги при детализации

В детальной строке показатель содержит **исходное значение поля записи** без применения агрегатной функции. Например, если для показателя выбрана функция `Count`, а значение поля записи равно `7`, детальная строка показывает `7`; количество записей вычисляется на уровне группы и итогов.

При группировке колонок значение выводится только под соответствующей комбинацией группировок. Остальные ячейки показателя в этой строке остаются пустыми. Если группа колонок свёрнута, значение отображается под соответствующим родительским заголовком. В итоговых колонках детальной строки, если они включены, также выводится исходное значение показателя этой записи.

Групповые, промежуточные и общие итоги рассчитываются по исходным записям. Включение детализации, выбор дополнительных полей и сворачивание групп не изменяют результаты `Sum`, `Count`, `Min`, `Max` и `Average`. Отображение итогов управляется настройками **Итоги по строкам** и **Итоги по колонкам**.

Например, группа содержит два документа с суммами `10` и `20`. При раскрытии видны две детальные строки с этими значениями. Для показателя `Average` агрегат группы и соответствующий общий итог равны `15` как при раскрытой, так и при свёрнутой группе.

Детализация использует уже загруженные данные источника компонента и не выполняет дополнительный запрос исходных записей. Если источник возвращает предварительно агрегированные данные, детальные строки показывают именно эти записи.

## Фильтры

Панель данных поддерживает механизм настраиваемых фильтров, интегрированный с построителем запросов BaSYS. Фильтры позволяют пользователю задавать параметры отбора данных при формировании отчёта. Подробное описание настройки и использования фильтров приведено в отдельной статье — [Настраиваемые фильтры](filters.md).

Значения фильтров запоминаются для каждого пользователя отдельно и восстанавливаются при следующем открытии панели. Сохранение выполняется после успешного построения, поэтому изменение фильтров без построения не запоминается. Вернуть фильтры к значениям по умолчанию можно пунктом **Стандартные настройки** в меню действий. См. статью [Пользовательские настройки форм](../userInterface/userFormPreferences.md).
