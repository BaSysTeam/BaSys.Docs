# Макет на базе PDF

Макет на базе PDF — готовый документ `.pdf`, в котором места для значений размечены текстовыми полями PDF-формы (AcroForm). Имя поля — путь к данным. Поле **Вид разметки** в конструкторе скрыто: новые печатные формы с видом макета PDF всегда размечаются полями. Ранее сохранённые печатные формы с текстовыми метками открываются и печатаются без изменений.

При построении печатной формы платформа читает макет, подставляет данные из [контекста](dataRetrieval.md) и формирует новый PDF-документ. Результат — законченный документ с точной геометрией, не требующий у получателя Excel; он открывается в новой вкладке браузера во встроенном просмотрщике.

## Как подготовить макет

### Конвертация макета Excel в PDF

Наиболее продуктивный путь — сконвертировать уже существующий [Excel-макет](excelTemplate.md), а не рисовать документ с нуля. Конвертер переносит в PDF:

- размер и ориентацию страницы, поля — из параметров страницы листа (по умолчанию A4, портрет); используемый диапазон масштабируется по ширине печатной области, если не влезает;
- границы ячеек (стиль, толщина, цвет) и заливки;
- статичный текст со шрифтом, размером, начертанием, цветом, выравниванием и переносом по словам;
- внутренний отступ ячейки: базовый зазор плюс `indent` ячейки со стороны выравнивания;
- объединённые ячейки — как один блок или одно поле;
- картинки — по позиции и размеру якорной ячейки;
- маркеры значений `{% raw %}{{путь}}{% endraw %}` — в поля PDF-формы с именем-путём;
- именованные диапазоны книги — в полосы вывода табличных частей (поля-контейнеры);
- формат числа и даты из формата ячейки Excel — в суффикс `|формат` (см. ниже);
- признак «Переносить по словам» — в модификатор `~`.

Порядок работы:

1. В карточке печатной формы с видом макета Excel и загруженным файлом нажмите **Скачать PDF (поля)**. Конвертер ничего не сохраняет в системе: он просто отдаёт файл.
2. Откройте полученный файл и прочитайте последнюю страницу **«Требует доводки»** — на ней перечислены предупреждения конвертации: составные строки с текстом и маркерами вперемешку, непереводимые выражения `ClosedXML.Report`, непереводимые форматы ячеек.
3. **Удалите страницу «Требует доводки»** — она не является частью макета.
4. Доработайте макет в редакторе PDF: проверьте границы полей, выравнивание, размеры шрифтов.
5. Создайте новую печатную форму с видом макета **PDF** и загрузите файл. Перевести существующую Excel-печатную форму на PDF нельзя — вид макета не изменяется.

Пиксельное совпадение с исходным листом Excel не гарантируется: конвертер даёт стартовый макет, который в общем случае требует доводки.

### Редакторы для подготовки и доводки макетов

Рекомендуемые продукты:

- **Adobe Acrobat** (Pro) — полноценная работа с полями формы, точное позиционирование, надёжное сохранение имён полей;
- **Master PDF Editor** — более доступная альтернатива с тем же набором возможностей по работе с полями и содержимым.

**Scribus для доводки сконвертированных макетов не подходит**: при открытии и сохранении он ломает такой макет. Использовать его можно разве что для макетов, рисуемых в нём с нуля, — но и в этом случае результат нужно проверять построением печатной формы.

При работе в любом редакторе проверяйте, что имена полей сохраняются без искажений: путь к данным может содержать кириллицу, подчёркивания и символ `|` (разделитель формата).

## Пути к данным

Место для значения задаётся **путём к данным** — `имя_переменной.сегмент.сегмент`. Первый сегмент — имя переменной контекста: `header`, имя табличной части или имя источника данных. Дальнейшие сегменты разрешаются по типу значения: колонка `DataRow`, ключ словаря, свойство объекта.

Имена допускают кириллицу и подчёркивания: `header.юр_лицо_display`.

Один путь может встречаться в макете сколько угодно раз — значение выводится в каждое место. Путь, который не удалось разрешить (нет переменной, нет колонки), даёт пустую строку и предупреждение в журнале построения с указанием пути и страницы.

### Формат значения

Формат задаётся суффиксом `|формат` после пути:

```
header.date|dd.MM.yyyy
items.sum|N2
```

Это строка формата .NET, применяемая в культуре текущего запроса. Значения `DateTime` с `Kind = Utc` и `DateTimeOffset` перед выводом переводятся в локальное время сервера. Без суффикса `DateTime` в полночь выводится краткой датой культуры (`01.09.2026` для `ru-RU`), иначе — полным представлением с временем. `null` даёт пустую строку. Формат, неприменимый к типу значения, игнорируется с предупреждением.

### Перенос по словам

Перенос включается модификатором `~` — последним символом в имени поля, после необязательного формата:

```
header.предмет_договора~
header.дата_начало|dd.MM.yyyy~
```

Модификатор равноправен флагу `Multiline` у поля — достаточно любого из двух, потому что не всякий редактор позволяет выставить флаг. Модификатор не входит в путь: сопоставление с полосой, спецпеременные и текст предупреждений работают по пути без `~`.

Высота области под перенесённое значение не растёт: строки, не влезшие по высоте, отбрасываются с предупреждением, шрифт не уменьшается.

### Спецпеременные

Имена с ведущим подчёркиванием зарезервированы платформой. Если у автора есть своя переменная `_page` или колонка `_row_number`, данные автора приоритетнее — это не считается ошибкой.

| Имя                     | Значение                                     |
| :---------------------- | :------------------------------------------- |
| `_page._number`         | Номер текущей страницы результата, с 1.      |
| `_page._count`          | Число страниц результата.                    |
| `<полоса>._row_number`  | Номер строки в полосе, с 1.                  |

## Полосы: вывод табличных частей

**Полоса** — область макета, размножаемая по строкам коллекции. Имя полосы — имя переменной контекста, значение которой является `DataTable` или списком (табличная часть объекта либо источник данных, вернувший коллекцию). Скаляр или объект под именем полосы — ошибка сборки.

Полоса задаётся полем-контейнером, имя которого равно имени табличной части (например, `row_1`). Поля колонок с именами `row_1.колонка` должны геометрически лежать внутри прямоугольника контейнера на той же странице. Контейнер может не содержать полей — тогда полоса просто повторяется по числу строк. Собственный текст контейнера не выводится.

Поле `имя.колонка` вне полосы `имя` — ошибка сборки.

Высота строки полосы фиксирована и равна высоте полосы в макете. Вложенные полосы и группировки не поддерживаются; пересечение полос по вертикали — ошибка сборки.

### Зоны страницы и многостраничность

Страница макета делится на зоны: всё выше первой полосы (шапка), сами полосы, промежутки между ними, всё ниже последней полосы (подвал). Строки полосы выводятся сверху вниз с накопленным сдвигом, а зоны ниже «подъезжают» к последней выведенной строке. Полоса с нулём строк не выводится вовсе.

Зоны ниже полосы измеряются по фактическому содержимому, а не по геометрии бумаги: пустое место под макетом не резервируется и не мешает росту полосы, а содержимое подвала прижимается к последней строке.

Если очередная строка полосы не помещается до нижней границы страницы за вычетом содержимого всего, что ниже полосы, начинается новая страница результата. Шапка выводится один раз — на первой странице; на страницах-продолжениях строки полосы начинаются от верхнего отступа макета. Подвал выводится один раз — на последней странице. Повторяемые заголовки и подвалы полосы не поддерживаются.

Страницы макета без полос выводятся как есть, по одной странице результата. Многостраничный макет обрабатывается страница за страницей.

> **Ограничение.** Если макет залит фоном или обведён рамкой по всему листу, содержимое доходит до края бумаги и места под рост полосы не остаётся: на страницу попадёт столько строк, сколько влезает до низа самой полосы. Фон и рамку в таком макете нужно ограничить областью содержимого.

## Особенности разметки полями

Разметкой служат текстовые поля AcroForm. Имя поля — путь к данным с необязательным суффиксом формата: `header.number`, `header.дата|dd.MM.yyyy`.

Редактор может разложить имя `header.number` в иерархию полей `header` → `number`, поскольку точка в PDF является разделителем имён. Это штатное поведение: платформа собирает полное имя по цепочке родительских полей и только затем разбирает путь. Несколько полей с одним именем заполняются все.

Из поля берутся: страница, прямоугольник `/Rect`, шрифт, размер и цвет из `/DA`, выравнивание `/Q` (0 — влево, 1 — по центру, 2 — вправо) и флаг `Multiline`. Размер шрифта `0` трактуется как 10 pt. Ограничение `/MaxLen`, режим `Comb`, чекбоксы, кнопки и списки игнорируются с предупреждением.

Однострочное поле выводит значение в одну строку с выравниванием из `/Q`; не влезшее по ширине значение обрезается без многоточия. При включённом переносе значение раскладывается на строки по ширине прямоугольника, а строки, не влезшие по его высоте, отбрасываются — поверх содержимого ниже они не рисуются. Любая обрезка попадает в журнал построения.

Отсутствие полей PDF-формы (AcroForm) в макете — ошибка сборки.

## Результат печати

Результат — новый документ `.pdf`, который открывается в новой вкладке браузера (`Content-Disposition: inline`) под именем `<Заголовок печатной формы>_<дата и время>.pdf`.

Результат не является интерактивной формой: в нём нет AcroForm и виджетов, значения впечатаны в содержимое страницы. По умолчанию разрешены печать и извлечение текста (в том числе для программ чтения с экрана), запрещены изменение документа, аннотирование, заполнение форм и сборка документа; пароль на открытие не устанавливается.

Значения выводятся встроенными в платформу шрифтами Liberation Sans, Liberation Serif и Liberation Mono, поэтому результат не зависит от набора шрифтов на сервере. Шрифт макета сопоставляется с ними по имени: `Times`, `Serif`, `Georgia` — Liberation Serif; `Courier`, `Mono` — Liberation Mono; всё остальное — Liberation Sans. Начертание определяется по имени и флагам шрифта. Шрифты статичной части макета не затрагиваются — она попадает в результат как есть.

## Диагностика сборки

Сообщения сборки возвращаются вместе с результатом и попадают в журнал построения печатной формы. Ошибка прерывает построение, предупреждение оставляет результат.

| Ситуация                                                            | Уровень                          |
| :------------------------------------------------------------------ | :------------------------------- |
| В макете нет полей PDF-формы (AcroForm)                             | ошибка                           |
| Вложенность или пересечение полос                                    | ошибка                           |
| Поле `имя.колонка` вне полосы `имя`                                  | ошибка                           |
| Значение под именем полосы — не коллекция                            | ошибка                           |
| Макет зашифрован или не открывается                                  | ошибка                           |
| Путь к данным не разрешился                                          | предупреждение, пустая строка    |
| Обрезка значения по ширине                                           | предупреждение                   |
| Многострочное значение не влезло по высоте, лишние строки отброшены  | предупреждение                   |
| Неподдерживаемый тип поля, `/MaxLen`, `Comb`                         | предупреждение                   |
| Формат неприменим к типу значения                                    | предупреждение                   |

## Рекомендации

- **Считайте итоги в [источниках данных](dataRetrieval.md).** В PDF-результате формул нет вообще, поэтому любые суммы и количества должны приходить готовыми значениями.
- **Не заливайте фон и не обводите рамкой весь лист** — иначе полосе не остаётся места для роста, и строки будут уходить на новые страницы раньше, чем нужно.
- **Задавайте полю достаточную высоту**: область переноса не расширяется за счёт содержимого ниже.
- **Проверяйте вывод кириллицы и длинных значений** на реальных данных: обрезка и отброшенные строки видны только в журнале построения.
- **Начинайте с конвертации Excel-макета**: доводить готовую геометрию быстрее, чем размещать элементы с нуля.
