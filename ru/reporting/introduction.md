# Отчётность. Введение

В системе **BaSYS** на уровне платформы реализованы механизмы для построения отчётов. Существуют стандартные (поставляемые вместе с платформой) виды [метаданных](../metadata/index.md): **Панель данных** (Data view) и **Отчёт Excel** (Excel report).

## Панель данных

Панель данных позволяет визуализировать данные при помощи различных компонентов: гистограммы, линейного графика, круговой и кольцевой диаграмм, индикатора значения и индикатора-шкалы (gauge). Кроме того, Панель данных поддерживает вывод данных в виде таблицы и сводной таблицы. Извлечение данных осуществляется при помощи [построителя запросов](../calculations/queryBuilder.md) BaSYS.

Панель данных рекомендуется как основной инструмент быстрого создания отчётов. Она не обязательно должна содержать все доступные компоненты визуализации — Панель данных может состоять из единственной таблицы (простой табличный отчёт) или одной сводной таблицы. Панели с множественными индикаторами и графиками по функциональности представляют собой dashboard.

Подробнее — в разделе [Панели данных](dataView.md).

## Отчёт Excel

Отчёт Excel позволяет создавать отчёты на базе макетов, разработанных в Excel. Данные извлекаются из базы данных при помощи [построителя запросов](../calculations/queryBuilder.md) BaSYS и могут быть обработаны с использованием [библиотеки функций](../calculations/index.md) BaSYS (например, работа с табличными данными поддерживается при помощи [DataTable](../calculations/dataTable.md)). Вывод данных осуществляется с использованием библиотеки [ClosedXML.Report](https://github.com/closedxml/closedxml.report), которая позволяет разметить лист Excel для наполнения его данными.

Отчёт Excel рекомендуется использовать, когда необходимо специфическое форматирование макета. Кроме того, он позволяет создавать отчёты типа «регламентированная отчётность», в которых каждое значение является результатом отдельного расчёта. Следует учитывать, что Отчёт Excel более ресурсоёмкий, чем Панель данных, т.к. формирование файла Excel — ресурсоёмкая операция. Если один и тот же отчёт реализуем обоими способами, предпочтение следует отдавать Панели данных по соображениям производительности.

Подробнее — в разделе [Отчёт на базе Excel](excelReport.md).

## Настраиваемые фильтры

Панель данных и Отчёт Excel содержат механизм настраиваемых фильтров, интегрированный с построителем запросов BaSYS. Подробнее — в разделе [Настраиваемые фильтры](filters.md).

## Произвольные отчёты

Если необходимо разработать уникальные отчёты, которые не укладываются в рамки Панели данных и Отчёта Excel, рекомендуется создать отдельный вид метаданных (например, «Произвольный отчёт»), который не хранит данные и использует [формы](../userInterface/index.md). Требуемая функциональность разрабатывается на базе программируемых форм с использованием всех возможностей Vue.js.
