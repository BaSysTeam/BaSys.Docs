# Команды. Введение

В системе **BaSYS** команды предназначены для выполнения действий по нажатию пользователем кнопки или пункта меню. Команды делятся на две категории: **программируемые** и **стандартные**.

## Программируемые команды

[Программируемые команды](programmableCommands.md) содержат логику на языке JavaScript с использованием функций библиотеки [BaSYS.Fx](../calculations/index.md). Код выполняется на клиенте (в браузере). Обращения к базе данных возможны при помощи [построителя запросов](../calculations/queryBuilder.md) BaSYS.

В контексте выполнения команды доступен объект данных (DataObject): к полям шапки можно обращаться через `$h.<имя_колонки>`, к табличным частям — через `$t.<имя_таблицы>`. Помимо функций BaSYS.Fx, в командах доступны специальные функции управления формой: `save()`, `recalculate()`, `refresh()`, `openDialog()` и другие.

Частными случаями программируемых команд являются команды **подбора** и **заполнения** табличной части. Они упрощают программирование типовых действий: разработчику достаточно задать выражение — источник данных, а остальную логику система выполняет автоматически. При необходимости подбор и заполнение могут быть запрограммированы полностью.

Программируемые команды доступны в автоматических формах и формах, созданных конструктором. В автоматических формах команды размещаются в подменю «Действия» шапки или соответствующей табличной части. В формах конструктора команда привязывается к кнопке или пункту меню по имени.

## Стандартные команды

[Стандартные команды](standardCommands.md) — это фиксированный набор действий, предусмотренных интерфейсом: записать, вернуться в список, добавить строку, экспорт в Excel, пересчитать и т.д. Стандартные команды привязываются к элементам формы конструктора по имени (например, `standard.save`, `standard.return`).

## Программируемые формы

В программируемых формах механизм команд не используется, поскольку форма полностью программируется на JavaScript с использованием Vue.js, и разработчик самостоятельно реализует обработку действий пользователя.
