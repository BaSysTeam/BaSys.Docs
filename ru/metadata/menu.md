# Меню

В системе BaSYS объекты метаданных вида **Menu** описывают навигационное меню пользовательского приложения. Меню рендерится в боковой панели интерфейса (компонент `NavigationPanelComponent.vue`) и формируется на стороне сервера по сохранённым настройкам.

В качестве визуального компонента используется [PrimeVue MegaMenu](https://v3.primevue.org/megamenu/) (вертикальная ориентация). Поэтому модель настроек меню в BaSYS повторяет иерархическую структуру элементов, ожидаемую компонентом MegaMenu: корневая группа → колонки → подгруппы (заголовки колонок) → пункты-ссылки.

Объект метаданных вида **Menu** не хранит пользовательские данные и не использует пользовательские формы — это стандартный системный вид метаданных, настройки которого описывают только структуру меню (см. [Модель метаданных](introduction.md)).

В системе может существовать несколько объектов вида **Menu**. При построении бокового меню в приложении сервер обходит **все активные** объекты, проверяет права доступа текущего пользователя и объединяет видимые группы каждого объекта в общий список. Это позволяет разнести разделы меню по нескольким объектам метаданных (например, отдельное меню для подсистем, ролей или прикладных модулей) и независимо управлять их составом и доступом.

## Режимы заполнения

Для группы меню верхнего уровня предусмотрены два режима:

- **Ручной режим** (`autoFill = false`) — состав группы полностью задаётся разработчиком: колонки, подгруппы и ссылки добавляются и упорядочиваются вручную в конструкторе.
- **Автоматический режим** (`autoFill = true`) — содержимое группы строится сервером на основании выбранного вида метаданных (`metaObjectKindUid`). При построении меню сервис `MenusService` получает все объекты метаданных указанного вида, отфильтровывает их по правам доступа и по флагу **isActive**, после чего раскладывает по колонкам по `itemsPerColumn` элементов. Для каждого объекта формируется ссылка вида `/app#/data-objects/{kindName}/{objectName}`.

Автоматический режим удобен, когда состав меню должен изменяться вместе с составом объектов метаданных (например, список справочников или документов), без правки настроек меню.

## Структура модели

Модель настроек меню (`MenuSettings`) имеет четыре уровня вложенности:

```
MenuSettings
└── items: MenuSettingsGroupItem[]        // Корневые элементы меню (группы/ссылки/разделители)
    └── items: MenuSettingsColumn[]       // Колонки внутри группы
        └── items: MenuSettingsSubItem[]  // Подгруппы (заголовки колонок)
            └── items: MenuSettingsLinkItem[] // Конечные ссылки и разделители
```

## MenuSettings

Корневой объект настроек меню. Содержит общие свойства объекта метаданных и список корневых элементов.

- **uid** (`GUID`) — Уникальный идентификатор объекта, назначается автоматически.
- **title** (`String`) — Заголовок меню, отображаемый в интерфейсе конструктора. Максимальная длина 100 символов.
- **name** (`String`) — Текстовый идентификатор объекта метаданных. Должен содержать только латинские буквы в нижнем регистре, цифры и символ подчеркивания. Максимальная длина 30 символов. Используется в URL-маршрутах конструктора.
- **memo** (`String`) — Произвольная текстовая информация. Максимальная длина 300 символов.
- **isActive** (`Boolean`) — Признак активности. Только активные объекты вида **Menu** учитываются при построении бокового меню приложения.
- **version** (`Long`) — Версия настроек. Используется для контроля изменений.
- **items** ([`MenuSettingsGroupItem[]`](#menusettingsgroupitem)) — Список корневых элементов меню.

## MenuSettingsGroupItem

Корневой элемент меню. В зависимости от значения свойства **kind** интерпретируется как группа, одиночная ссылка или разделитель.

- **uid** (`GUID`) — Уникальный идентификатор элемента, назначается автоматически.
- **kind** (`Integer`) — Тип элемента. Допустимые значения:
  - `1` — **Link**: одиночная ссылка верхнего уровня (без вложенных колонок).
  - `2` — **Separator**: визуальный разделитель между группами.
  - `3` — **Group**: группа со вложенными колонками и подгруппами (значение по умолчанию).
- **title** (`String`) — Заголовок элемента, отображаемый в меню. Для разделителя не используется.
- **iconClass** (`String`) — CSS-класс иконки, отображаемой слева от заголовка. Используются классы [PrimeIcons](https://primevue.org/icons/), например `pi pi-folder`.
- **url** (`String`) — Адрес перехода. Применяется только для `kind = Link`. Может содержать абсолютный или относительный URL, в том числе hash-маршруты приложения (например, `/app#/data-objects/catalog/products`).
- **isVisible** (`Boolean`) — Признак видимости элемента. Невидимые элементы исключаются при построении меню.
- **autoFill** (`Boolean`) — Включает автоматический режим заполнения группы (см. [Режимы заполнения](#режимы-заполнения)). Применяется только для `kind = Group`.
- **metaObjectKindUid** (`GUID`) — Идентификатор вида метаданных, по объектам которого строится автоматическое заполнение. Обязателен при `autoFill = true`.
- **itemsPerColumn** (`Integer`) — Количество элементов в одной колонке при автоматическом заполнении. По умолчанию `10`.
- **items** ([`MenuSettingsColumn[]`](#menusettingscolumn)) — Список колонок группы. Заполняется вручную в ручном режиме; в автоматическом режиме игнорируется и колонки строятся сервером.

## MenuSettingsColumn

Колонка группы меню. Соответствует одной визуальной колонке во всплывающей панели MegaMenu. В одной группе может быть несколько колонок — они отображаются рядом по горизонтали.

- **uid** (`GUID`) — Уникальный идентификатор колонки, назначается автоматически.
- **items** ([`MenuSettingsSubItem[]`](#menusettingssubitem)) — Список подгрупп (заголовков с пунктами) внутри колонки.

## MenuSettingsSubItem

Подгруппа внутри колонки. Визуально представляет собой заголовок секции, под которым перечислены ссылки.

- **uid** (`GUID`) — Уникальный идентификатор подгруппы, назначается автоматически.
- **title** (`String`) — Заголовок подгруппы, отображаемый над списком ссылок.
- **isVisible** (`Boolean`) — Признак видимости подгруппы.
- **items** ([`MenuSettingsLinkItem[]`](#menusettingslinkitem)) — Список ссылок и разделителей внутри подгруппы.

## MenuSettingsLinkItem

Конечный элемент меню — ссылка или разделитель внутри подгруппы.

- **uid** (`GUID`) — Уникальный идентификатор элемента, назначается автоматически.
- **kind** (`Integer`) — Тип элемента. Допустимые значения:
  - `1` — **Link**: пункт-ссылка.
  - `2` — **Separator**: горизонтальный разделитель между ссылками.
- **title** (`String`) — Текст ссылки. Для разделителя не используется.
- **iconClass** (`String`) — CSS-класс иконки ссылки (классы [PrimeIcons](https://primevue.org/icons/)).
- **url** (`String`) — Адрес перехода. Используется только для `kind = Link`.
- **isVisible** (`Boolean`) — Признак видимости ссылки.

## Построение меню на стороне сервера

Сборка результирующего меню для текущего пользователя выполняется сервисом `MenusService` (`BaSys.App.Services.MenusService`). Алгоритм:

1. Загружаются все активные объекты метаданных вида **Menu**.
2. Для каждого объекта проверяется право доступа текущего пользователя к данному меню; если доступа нет — объект пропускается.
3. Для каждой корневой группы (`MenuSettingsGroupItem`):
   - элементы с `isVisible = false` пропускаются;
   - группы с `autoFill = false` заполняются по сохранённой иерархии колонок/подгрупп/ссылок;
   - группы с `autoFill = true` заполняются по объектам выбранного вида метаданных с учётом прав доступа (`ReadRight` или `AccessRight`) и флага **isActive** объектов.
4. Сформированный список (`MenuGroupDto`) возвращается клиенту и передаётся в компонент `MegaMenu` с ориентацией `vertical`.
