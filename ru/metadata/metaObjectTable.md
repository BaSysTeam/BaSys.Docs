# Meta object table

**Meta object table** описывает структуру таблицы объекта метаданных и содержит следующие настройки:

- **uid** (`GUID`) — Уникальный идентификатор таблицы, назначается автоматически.
- **title** (`String`) — Название таблицы, которое будет отображаться в интерфейсе.
- **name** (`String`) — Текстовый идентификатор таблицы. Должен содержать только латинские буквы в нижнем регистре, цифры и символ подчеркивания.
- **memo** (`String`) — Произвольная текстовая информация о таблице.
- **columns** (`Array`) — Массив колонок таблицы. Содержит описание структуры полей таблицы. См. [Meta object table column](metaObjectTableColumn.md).
