# Модель метаданных

Основным подходом при разработке приложений в системе BaSYS является создание слоя метаданных,
который определяет структуру и логику бизнес-модели.

Модель метаданных в системе BaSYS двухуровневая. На верхнем уровне находятся виды объектов метаданных
(например, справочники, документы, отчеты, автоматизированные рабочие места и т.д.), которые определяют общие свойства и поведение объектов. 
На втором уровне находятся конкретные объекты метаданных, которые представляют собой экземпляры видов объектов.

У вида метаданных существует несколько фундаментальных свойств, которые определяют его назначение. 
Первое из них - флаг "Хранит данные" (Store data), который определяет, будет ли вид метаданных хранить данные в базе данных.
Если флаг установлен, то в базе данных будут созданы таблицы, предназначенные для хранения данных этого вида метаданных.
Примерами таких видов метаданных являются "Справочник" (Catalog), "Операция" (Operation), "Регистр" (Регистр). 
Такие объекты метаданных мы называем [**Data Objects**](dataObject.md).

Если флаг "Хранит данные" не установлен, то объекты данного вида не хранят данные в базе данных, 
а служат для визуального отображения. Для объектов такого вида следует устанавливать флаг "Использовать формы", 
чтобы система позволила создавать пользовательски формы у объектов данного вида. 
Примерами таких объектов являются "Отчет" (Report), Рабочий стол (Desktop), Дашборд (Dashboard), 
"Автоматизированное рабочее место" (Automated workplace). Подобные объекты метаданных мы называем ViewObjects.

Также возможна ситуация когда вид метаданных не хранит данные и при этом не имеет пользовательских форм. 
Обычно это стандартные виды метаданных, которые служат для реализации системных функций. 
Например, "Меню" (Menu), "Процесс" (Workflow). Стандартные виды метаданных создаются автоматически 
при первоначальном заполнении системы и не могут быть изменены пользователем.

Обобщенно вышесказанное можно представить в виде таблицы:

| Хранит данные | Использовать формы | Описание                                |
|---------------|--------------------|-----------------------------------------|
| Да            | Нет                | DataObject с автоматическими формами    |
| Да            | Да                 | DataObject с пользовательскими формами  |
| Нет           | Да                 | ViewObject с пользовательскими формами  |
| Нет           | Нет                | Стандартный вид метаданных              |

    
Настройки видом метаданных фундаментальным образом определяют поведение системы.
Исходя из нашего опыта, мы создали набор видов метаданных, применимых в большинстве случаев.
Эти виды метаданных создаются автоматически при первоначальном заполнении системы.
Пользователь может не использовать их и создать собственные виды метаданных — как замену, 
так и дополнение к предлагаемым по умолчанию.
Тем не менее, мы рекомендуем начать работу с предустановленными видами метаданных, особенно на этапе освоения системы.
