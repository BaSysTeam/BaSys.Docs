# Meta object table column

**Meta object table column** описывает настройки колонки таблицы объекта метаданных и содержит следующие настройки:

- **uid** (`GUID`) — Уникальный идентификатор колонки, назначается автоматически.
- **title** (`String`) — Название колонки, которое будет отображаться в интерфейсе.
- **name** (`String`) — Текстовый идентификатор колонки. Должен содержать только латинские буквы в нижнем регистре, цифры и символ подчеркивания.
- **formula** (`String`) — Формула для вычисляемых полей. Если пусто, поле не является вычисляемым.
- **itemsSource** (`String`) — Источник данных для списка элементов (для полей типа справочник).
- **isStandard** (`Boolean`) — Флаг, указывающий, является ли колонка стандартной системной колонкой.
- **renderSettings** (`Object`) — Настройки отображения колонки в интерфейсе. См. [Render Settings](#render-settings).
- **dataSettings** (`Object`) — Настройки данных колонки (тип данных, ограничения и т.д.). См. [Data Settings](#data-settings).

## Render Settings

Объект **RenderSettings** содержит настройки отображения колонки, используемые при генерации автоматических форм:

- **controlKindUid** (`GUID`) — Уникальный идентификатор типа элемента управления для отображения поля.
- **showInList** (`Boolean`) — Определяет, отображается ли колонка в списке. По умолчанию true.
- **listColumnWidth** (`String`) — Ширина колонки в списке. Если пусто, ширина определяется автоматически.

## Data Settings

Объект **dataSettings** содержит настройки данных колонки:

- **dataTypeUid** (`GUID`) — Уникальный идентификатор типа данных колонки.
- **stringLength** (`Integer`) — Максимальная длина строкового поля. Применяется только для строковых типов данных.
- **numberDigits** (`Integer`) — Количество знаков после запятой для числовых типов данных.
- **primaryKey** (`Boolean`) — Определяет, является ли колонка первичным ключом таблицы.
- **required** (`Boolean`) — Определяет, является ли поле обязательным для заполнения.
- **unique** (`Boolean`) — Определяет, должны ли значения в колонке быть уникальными.
- **defaultValue** (`String/null`) — Значение по умолчанию для колонки. Может быть null, если значение по умолчанию не задано.
