# Data object

**Data Object** — это объект системы, предназначенный для хранения данных. В общем виде **Data Object** состоит из основной таблицы (часто называемой «Шапка» или Header) и некоторого количества табличных частей (**Detail tables**). Наличие табличных частей не является обязательным.

Структура **Data Object** описывается следующими настройками:

- **uid** (`GUID`) — Уникальный идентификатор объекта, назначается автоматически.
- **metaObjectKindUid** (`GUID`) — Уникальный идентификатор вида объекта метаданных.
- **editMethod** (`Integer`) — Определяет способ редактирования объекта: на отдельной странице или в модальном окне. 0 - на странице, 1 - в диалоге. По умолчанию - 0.
- **title** (`String`) — Название элемента, которое будет отображаться в интерфейсе. Максимальная длина 100 символов.
- **name** (`String`) — Текстовый идентификатор объекта метаданных. Должен содержать только латинские буквы в нижнем регистре, цифры и символ подчеркивания. Максимальная длина — 30 символов. Используется при создании таблиц базы данных и в ссылках на формы данного объекта метаданных.
- **memo** (`String`) — Произвольная текстовая информация. Максимальная длина 300 символов.
- **orderByExpression** (`String`) — Выражение, определяющее порядок сортировки элементов в списке. Если не задано, по умолчанию используется выражение, определенное для вида метаданных. Если задано, оно заменяет выражение по умолчанию для данного объекта метаданных. Выражение должно содержать имена полей сортировки с направлением сортировки, разделенные запятыми. Если направление сортировки не указано, подразумевается сортировка по возрастанию. Примеры: "title", "number desc, date desc".
- **displayExpression** (`String`) — Выражение, определяющее отображение объекта данного вида. Если не задано, по умолчанию используется выражение, определенное для вида метаданных. Если задано, оно заменяет выражение по умолчанию для данного объекта метаданных. Выражение может содержать или имя поля или шаблон отображения, в котором поля указаны в двойных фигурных скобках {{field_name}}. Примеры: "title", "Операция №{{number}} от {{date}}".
- **listFormUid** (`String`) — Уникальный идентификатор формы списка. Если пусто, то будет сгенерирована автоматическая форма списка.
- **itemFormUid** (`String`) — Уникальный идентификатор формы элемента. Если пусто, то будет сгенерирована автоматическая форма элемента.
- **isActive** (`Boolean`) — Если включено, то объект добавляется в меню с автоматическим заполнением.
- **header** ([`MetaObjectTable`](metaObjectTable.md)) — Описание настроек таблицы шапки. Имя таблицы всегда **header**.
- **detailTables** ([`MetaObjectTable[]`](metaObjectTable.md)) — Описание настроек табличных частей (**Detail tables**), если таковые есть у **Data object**.
