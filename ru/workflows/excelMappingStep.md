# Мэппинг Excel

Шаг **Мэппинг Excel** (`excel_mapping`) извлекает данные из Excel-файла, преобразуя колонки листа в типизированную таблицу по заданным правилам соответствия (маппинга). Шаг принимает бинарные данные файла от предыдущего шага (обычно — шага «Чтение файла»), открывает указанный лист, считывает заголовки колонок и построчно заполняет результирующую таблицу.

Результат — объект `DataTable`, доступный последующим шагам через `_data.<имя_шага>`.

## Настройки

### SourcePath

Имя шага, из результата которого берутся бинарные данные Excel-файла. Шаг-источник должен возвращать массив байтов (`byte[]`) — например, шаг «Чтение файла» с `OutputFormat = Binary`.

Значение должно точно совпадать с полем `Name` шага-источника.

### SheetName

Имя листа (worksheet) в Excel-файле, из которого производится чтение. Значение чувствительно к регистру и должно совпадать с именем вкладки в файле.

### StartRow

Номер строки, содержащей заголовки колонок. Нумерация начинается с 1. Значение по умолчанию — `1`.

Данные считываются начиная со строки `StartRow + 1`. Например, если `StartRow = 7`, строка 7 интерпретируется как заголовки, а данные читаются начиная со строки 8.

### EndRow

Номер последней строки для чтения. Если значение равно `0` или превышает фактическое количество строк на листе, чтение продолжается до последней заполненной строки.

Значение по умолчанию — `0` (читать до конца).

### Mapping

Коллекция правил соответствия колонок Excel полям результирующей таблицы. Каждый элемент описывает одну колонку для извлечения.

Структура элемента `ExcelMappingRow`:

| Поле                   | Тип    | Описание                                                        |
|------------------------|--------|-----------------------------------------------------------------|
| `Uid`                  | string | Уникальный идентификатор правила (GUID, генерируется автоматически) |
| `SourceFieldName`      | string | Заголовок колонки в Excel-файле (из строки `StartRow`)          |
| `DestinationFieldName` | string | Имя поля в результирующей таблице                               |
| `DataTypeUid`          | string | UID типа данных для преобразования значений ячеек               |

#### SourceFieldName

Текст заголовка колонки в Excel. Шаг ищет точное совпадение с текстом ячейки в строке `StartRow`. Если колонка с указанным заголовком не найдена, в лог записывается ошибка, но обработка строки продолжается.

#### DestinationFieldName

Имя колонки в результирующем `DataTable`. Используется для обращения к данным в последующих шагах (например, в скрипте).

#### DataTypeUid

Идентификатор примитивного типа данных BaSYS. Определяет, в какой тип .NET будет преобразовано значение ячейки. Допустимые типы:

| DataTypeUid                            | Тип      | .NET тип   |
|----------------------------------------|----------|------------|
| `0234c067-7868-46b2-ba8e-e22fae5255cb` | String   | `string`   |
| `b327f82a-ea96-416f-9836-785db28eccac` | Int      | `int`      |
| `daa57cb0-32eb-4709-b61f-4ea023ae31c3` | Long     | `long`     |
| `4bff64cf-eb01-4933-9f3d-b902336751f4` | Bool     | `bool`     |
| `a05516ac-baae-4f66-9b67-6703998a6a1b` | Decimal  | `decimal`  |
| `9001eafb-efb1-442f-b288-723bb8002b12` | DateTime | `DateTime` |
| `6fa9c45b-f514-4fea-a480-8e940636a1df` | Guid     | `Guid`     |

## Результат шага

После выполнения результат сохраняется как `DataTable` и доступен последующим шагам через `_data.<имя_шага>`. Таблица содержит колонки, определённые в `Mapping`, с типами данных, соответствующими `DataTypeUid`. Каждая строка таблицы соответствует строке Excel-файла (начиная со строки `StartRow + 1`).

Если значение ячейки не может быть преобразовано или ячейка пуста, в соответствующее поле записывается `null` (`DBNull`).

## Обработка ошибок

Шаг завершает процесс со статусом `Terminated` в следующих случаях:

- Шаг-источник, указанный в `SourcePath`, не найден в данных процесса.
- Результат шага-источника не является массивом байтов (`byte[]`).
- Бинарные данные файла пусты (`null`).
- Указан неизвестный `DataTypeUid` в одном из правил маппинга.

Если колонка с заголовком `SourceFieldName` не найдена на листе, шаг записывает ошибку в лог, но **не прерывает** процесс — обработка остальных колонок и строк продолжается.

## Пример: базовый маппинг

```json
{
  "sourcePath": "read_file",
  "sheetName": "Лист1",
  "startRow": 1,
  "endRow": 0,
  "mapping": [
    {
      "uid": "23d7af0c-ce8d-2eb5-db3c-0641266cb110",
      "sourceFieldName": "Марка",
      "destinationFieldName": "марки",
      "dataTypeUid": "0234c067-7868-46b2-ba8e-e22fae5255cb"
    },
    {
      "uid": "bb2a197b-e688-fae3-9710-b194489ff900",
      "sourceFieldName": "Кол-во, шт",
      "destinationFieldName": "колво_шт",
      "dataTypeUid": "a05516ac-baae-4f66-9b67-6703998a6a1b"
    }
  ],
  "kindName": "excel_mapping",
  "title": "Mapping",
  "name": "mapping",
  "isActive": true
}
```

Шаг берёт бинарные данные из результата шага `read_file`, открывает лист «Лист1», читает заголовки из строки 1 и извлекает данные начиная со строки 2 до конца листа. Колонка «Марка» сохраняется как строка в поле `марки`, колонка «Кол-во, шт» — как decimal в поле `колво_шт`.

## Пример: маппинг с нестандартной строкой заголовков

```json
{
  "sourcePath": "read_file",
  "sheetName": "ведомость",
  "startRow": 7,
  "endRow": 0,
  "mapping": [
    {
      "uid": "6da4f449-9c10-ea67-7d93-f7e8cf0e8771",
      "sourceFieldName": "Фамилия И.О.",
      "destinationFieldName": "сотрудник_title",
      "dataTypeUid": "0234c067-7868-46b2-ba8e-e22fae5255cb"
    },
    {
      "uid": "a6170193-6fb4-3962-5771-5d1be9d73d94",
      "sourceFieldName": "Должность",
      "destinationFieldName": "должность",
      "dataTypeUid": "0234c067-7868-46b2-ba8e-e22fae5255cb"
    }
  ],
  "kindName": "excel_mapping",
  "title": "Mapping",
  "name": "mapping",
  "isActive": true
}
```

В этом примере заголовки расположены в строке 7 (например, файл содержит служебную шапку в строках 1–6). Данные считываются начиная со строки 8.

## Типичная цепочка шагов

Шаг Excel-маппинга используется в связке с шагом чтения файла. Стандартный сценарий загрузки данных из Excel:

1. **Скрипт** — определяет UID файла (через запрос к данным или параметрам процесса).
2. **Чтение файла** — загружает файл из хранилища в бинарном формате (`OutputFormat = Binary`).
3. **Мэппинг Excel** — извлекает данные из файла по заданным правилам.
4. **Скрипт** — обрабатывает результат маппинга (фильтрация, трансформация, загрузка в объекты данных).

```json
{
  "steps": [
    {
      "kindName": "java_script",
      "name": "find_file",
      "title": "Find file"
    },
    {
      "regime": 1,
      "outputFormat": 0,
      "attachedFileUidExpression": "_data.find_file.rows[0].uid",
      "kindName": "read_file",
      "name": "read_file",
      "title": "Read file"
    },
    {
      "sourcePath": "read_file",
      "sheetName": "Sheet1",
      "startRow": 1,
      "endRow": 0,
      "mapping": [
        {
          "sourceFieldName": "Name",
          "destinationFieldName": "name",
          "dataTypeUid": "0234c067-7868-46b2-ba8e-e22fae5255cb"
        },
        {
          "sourceFieldName": "Amount",
          "destinationFieldName": "amount",
          "dataTypeUid": "a05516ac-baae-4f66-9b67-6703998a6a1b"
        }
      ],
      "kindName": "excel_mapping",
      "name": "mapping",
      "title": "Mapping"
    },
    {
      "kindName": "java_script",
      "name": "process_data",
      "title": "Process data"
    }
  ]
}
```

В скрипте `process_data` результат маппинга доступен как таблица:

```javascript
var table = _data.mapping;
for (var i = 0; i < table.rows.length; i++) {
  var row = table.rows[i];
  // row.name — строка, row.amount — число
}
```
