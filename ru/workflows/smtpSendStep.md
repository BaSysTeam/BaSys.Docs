# Отправить почту (SMTP)

Данный шаг предназначен для отправки почтовых сообщений по протоколу SMTP. Для выполнения отправки используется класс `SmtpClient`, предоставляемый платформой .NET Core.

Шаг позволяет сформировать и отправить электронное письмо с заданными параметрами подключения к SMTP-серверу, а также с настраиваемыми атрибутами сообщения, такими как отправитель, получатели, тема и содержимое письма.

## Параметры шага

### Параметры подключения к SMTP

- **Host** — строка, обязательный, поддерживается параметризация.  
  Имя или адрес SMTP-сервера.

- **Port** — число, обязательный, поддерживается параметризация.  
  Порт SMTP-сервера.

- **Пользователь** — строка, обязательный, поддерживается параметризация.  
  Имя пользователя для авторизации на SMTP-сервере.

- **Пароль** — строка, обязательный, поддерживается параметризация.  
  Пароль для авторизации на SMTP-сервере.

- **Таймаут** — число, поддерживается параметризация.  
  Таймаут ожидания операции отправки в секундах. Значение по умолчанию — `0` (без ограничения).

- **Включить SSL** — булево.  
  Признак необходимости использования защищённого соединения (SSL). Значение по умолчанию — `false`.

### Параметры почтового сообщения

- **Отправитель** — строка, обязательный, поддерживается параметризация.  
  Почтовый адрес отправителя.

- **Получатель** — строка, обязательный, поддерживается параметризация.  
  Почтовый адрес получателя.

- **Копия** — строка, поддерживается параметризация.  
  Почтовый адрес получателя копии (CC).

- **Скрытая копия** — строка, поддерживается параметризация.  
  Почтовый адрес получателя скрытой копии (BCC).

- **Тема** — строка, обязательный, поддерживается параметризация.  
  Тема письма.

- **Текст** — строка, поддерживается параметризация.  
  Содержимое письма. Может быть задано в текстовом или HTML-формате.

- **Тело письма в HTML** — булево.  
  Признак того, что содержимое письма задано в формате HTML.
