# Отправить почту (SMTP)

Данный шаг предназначен для отправки почтовых сообщений по протоколу SMTP. Для выполнения отправки используется класс `SmtpClient`, предоставляемый платформой .NET Core.

Шаг позволяет отправлять электронные письма с настраиваемыми параметрами подключения к SMTP-серверу и содержимым сообщения.

## Параметры шага

В таблицах ниже используются унифицированные типы параметров:
- `string` — строковое значение  
- `number` — числовое значение  
- `boolean` — логическое значение (`true / false`)

### Параметры подключения к SMTP

| Параметр         | Тип     | Обязательный | Параметризация | Значение по умолчанию | Описание |
|------------------|---------|--------------|----------------|------------------------|----------|
| **Host**         | string  | да           | да             | —                      | Имя или адрес SMTP-сервера |
| **Port**         | number  | да           | да             | —                      | Порт SMTP-сервера |
| **Пользователь** | string  | да           | да             | —                      | Имя пользователя для авторизации на SMTP-сервере |
| **Пароль**       | string  | да           | да             | —                      | Пароль для авторизации на SMTP-сервере |
| **Таймаут**      | number  | нет          | да             | `0`                    | Таймаут ожидания операции отправки в секундах (`0` — без ограничения) |
| **Включить SSL** | boolean | нет          | нет            | `false`                | Использовать защищённое соединение (SSL) |

### Параметры почтового сообщения

| Параметр                | Тип     | Обязательный | Параметризация | Значение по умолчанию | Описание |
|-------------------------|---------|--------------|----------------|------------------------|----------|
| **Отправитель**         | string  | да           | да             | —                      | Почтовый адрес отправителя |
| **Получатель**          | string  | да           | да             | —                      | Почтовый адрес получателя |
| **Копия (CC)**          | string  | нет          | да             | —                      | Почтовый адрес получателя копии |
| **Скрытая копия (BCC)** | string  | нет          | да             | —                      | Почтовый адрес получателя скрытой копии |
| **Тема**                | string  | да           | да             | —                      | Тема письма |
| **Текст**               | string  | нет          | да             | —                      | Содержимое письма (текст или HTML) |
| **Тело письма в HTML**  | boolean | нет          | нет            | `false`                | Признак того, что содержимое письма задано в формате HTML |
