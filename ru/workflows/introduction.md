# Процессы (Workflows)

**Процесс (workflow)** — это формализованный сценарий, состоящий из набора упорядоченных шагов, которые выполняются последовательно или по заданной логике. Каждый шаг представляет собой действие системы, например выполнение HTTP-запроса, чтение или запись данных в базу, преобразование данных или вызов внутреннего сервиса. Помимо прикладных шагов, процесс может включать управляющие конструкции, такие как ветвление (If), циклы (Loop) и другие элементы, позволяющие описывать сложную логику выполнения.

Процессы предназначены для решения задач интеграции с внешними системами, а также для внутренней автоматизации бизнес-логики в рамках **BaSYS**. С их помощью можно выстраивать цепочки действий без написания специализированного кода, описывая поведение системы декларативно. Кроме того, процессы используются как механизм расширения функциональности объектов системы, позволяя добавлять новую логику обработки данных и реакцию на события без изменения базовой архитектуры приложения.

Процесс может быть запущен несколькими способами в зависимости от сценария использования. Он может запускаться интерактивно через пользовательский интерфейс, автоматически по расписанию (например, для регламентных или фоновых задач), либо по событию — такому как создание или изменение **DataObject**.

Механизм процессов BaSYS основан на open-source фреймворке [Workflow-Core](https://github.com/danielgerlag/workflow-core), который обеспечивает инфраструктуру для описания, исполнения и отслеживания workflow. Использование готового фреймворка позволяет опираться на проверенную реализацию с поддержкой долгоживущих процессов, состояний и восстановления выполнения, одновременно сохраняя возможность расширять и адаптировать поведение процессов под требования платформы **BaSYS**.
