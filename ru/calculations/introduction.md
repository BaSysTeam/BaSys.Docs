# Вычисления. Введение

В системе **BaSYS** для выполнения расчётов и описания логики обработки данных используется язык программирования JavaScript (JS). JavaScript — один из самых популярных и широко используемых языков в мире. Им пользуются десятки миллионов разработчиков, и он стабильно занимает лидирующие позиции в рейтингах языков программирования. Благодаря своей гибкости, динамической природе и скриптовому стилю, JavaScript хорошо подходит для использования в low-code-системах, где часто требуется описывать вычисления и правила обработки данных в виде небольших фрагментов кода или формул. Несмотря на то, что у языка есть определённые особенности и ограничения, его простота и универсальность делают его удобным выбором для встроенного языка программирования.

Для решения прикладных задач на JavaScript мы разработали собственную библиотеку вспомогательных функций, которая подробно рассматривается в этом разделе. Особое внимание уделено работе с табличными данными: с одной стороны, в стандартной библиотеке JavaScript отсутствуют специализированные средства для их обработки, с другой — такие данные играют ключевую роль в автоматизации бизнес-процессов.

Кроме того, в библиотеку включён ряд других полезных функций, например, для работы с датами.
