# Прочие функции

## format
Форматирует значение (число, дату или логическое значение) в строку в соответствии с указанным форматом или параметрами.

### Синтаксис
```javascript
format(value, formatOrOptions)
```
### Параметры
- value: number \| Date \| boolean - значение, которое необходимо отформатировать.
- formatOrOptions *(необязательный)*: string \| NumberFormatOptions \| BooleanFormatOptions - строка формата или объект с параметрами форматирования. Тип параметра зависит от типа значения.

#### Форматирование чисел
Для числовых значений параметр может быть строкой формата или объектом NumberFormatOptions.

**Строка формата** — определяет количество десятичных знаков и группировку разрядов. 
Символ `.` отделяет целую часть от дробной, количество символов после `.` задает количество десятичных знаков. 
Наличие `,` в строке включает группировку разрядов (разделитель — пробел).

**NumberFormatOptions** — объект с полями:
- decimals: number — количество десятичных знаков от 0 до 100 (по умолчанию 2);
- decimalSeparator: string — разделитель целой и дробной части (по умолчанию `.`);
- groupSeparator: string — разделитель разрядов (по умолчанию пробел). Пустая строка отключает группировку.

Числовые значения округляются по тем же правилам, что и в [round](#round): до ближайшего значения, а при равном расстоянии — от нуля. Например, `format(1.005)` возвращает `'1.01'`, а `format(-1.5, '0')` — `'-2'`. Подробные правила вывода чисел приведены в описании [formatNumber](#formatnumber).

#### Форматирование дат
Для дат параметр задается строкой формата. Формат по умолчанию: `dd.MM.yyyy`.

Поддерживаемые токены:

| Токен | Описание                      | Пример |
| :---- | :---------------------------- | :----- |
| yyyy  | Полный год                    | 2025   |
| yy    | Двузначный год                | 25     |
| MM    | Месяц с ведущим нулем        | 01     |
| M     | Месяц без ведущего нуля      | 1      |
| dd    | День с ведущим нулем          | 05     |
| d     | День без ведущего нуля        | 5      |
| HH    | Часы (24ч) с ведущим нулем   | 14     |
| H     | Часы (24ч) без ведущего нуля | 9      |
| hh    | Часы (12ч) с ведущим нулем   | 02     |
| h     | Часы (12ч) без ведущего нуля | 2      |
| mm    | Минуты с ведущим нулем       | 05     |
| m     | Минуты без ведущего нуля     | 5      |
| ss    | Секунды с ведущим нулем      | 09     |
| s     | Секунды без ведущего нуля    | 9      |
| SSS   | Миллисекунды                 | 042    |

#### Форматирование логических значений
Для логических значений параметр задается объектом BooleanFormatOptions с полями:
- trueValue: string — строка для true (по умолчанию `'true'`);
- falseValue: string — строка для false (по умолчанию `'false'`).

### Возвращаемое значение
string — отформатированное строковое представление значения.

### Примеры

Число, два десятичных знака:
```javascript
var total = 1234.5;
var result = format(total, '#,##0.00');
// result: '1 234.50'
return result;
```

Число, три десятичных знака:
```javascript
var weight = 1072.1;
var result = format(weight, '#,##0.000');
// result: '1 072.100'
return result;
```

Дата:
```javascript
var dt = new Date(2025, 0, 15);
var result = format(dt, 'dd.MM.yyyy');
// result: '15.01.2025'
return result;
```

Дата со временем:
```javascript
var dt = new Date(2025, 0, 15, 14, 30, 0);
var result = format(dt, 'dd.MM.yyyy HH:mm');
// result: '15.01.2025 14:30'
return result;
```

## formatNumber
Форматирует число в строку. Поддерживает те же маски и параметры форматирования чисел, что и [format](#format).

### Синтаксис
```javascript
formatNumber(value, formatOrOptions)
```

### Параметры
- value: number — число, которое необходимо отформатировать.
- formatOrOptions *(необязательный)*: string \| NumberFormatOptions — строка формата или объект с параметрами `decimals`, `decimalSeparator` и `groupSeparator`, описанными в разделе [Форматирование чисел](#форматирование-чисел). По умолчанию выводятся два десятичных знака, разделитель целой и дробной части — точка, разделитель разрядов — пробел.

Точность вывода находится в диапазоне от 0 до 100. Дробное значение `decimals` усекается к нулю, `NaN` означает 0, а `null` или `undefined` сохраняют значение по умолчанию 2. Выход за допустимый диапазон после этого преобразования вызывает `RangeError`.

### Возвращаемое значение
string — отформатированное число с указанным количеством десятичных знаков. Недостающие знаки дополняются нулями.

### Правила округления и вывода
Число округляется по тем же правилам, что и в [round](#round), а результат дополняется нулями до заданного количества десятичных знаков. Например, `formatNumber(1.005)` возвращает `'1.01'`, а `formatNumber(1.2)` — `'1.20'`.

Конечные числа выводятся без экспоненты. Если результат округления равен нулю, знак минус не выводится. При допустимой точности значения `NaN`, `Infinity` и `-Infinity` возвращаются как строки `'NaN'`, `'Infinity'` и `'-Infinity'`; разделители и дополнение нулями к ним не применяются.

Начиная с версии BaSYS.FX 1.1.0, изменились результаты округления в **formatNumber** и числовом **format**: например, для `1.005` теперь получается `'1.01'` вместо `'1.00'`, а для `-0.004` — `'0.00'` вместо `'-0.00'`. При большой точности для `0.1` больше не выводятся цифры его двоичного представления. Существующие маски, группировка и пользовательские разделители сохраняются.

### Примеры
```javascript
formatNumber(1.005);       // '1.01'
formatNumber(-1.005);      // '-1.01'
formatNumber(-0.004);      // '0.00'
formatNumber(1.2);         // '1.20'
formatNumber(1234.5, '#,##0.000'); // '1 234.500'

formatNumber(1234.567, {
  decimals: 2,
  decimalSeparator: ',',
  groupSeparator: ' '
}); // '1 234,57'

formatNumber(0.1, { decimals: 20, groupSeparator: '' });
// '0.10000000000000000000'
formatNumber(1e21, { groupSeparator: '' });
// '1000000000000000000000.00'
formatNumber(Infinity);    // 'Infinity'

// format использует те же правила для числового значения.
format(1.005);             // '1.01'
```

## iif
Функция возвращает одно из двух значений в зависимости от переданного логического условия (condition). Является аналогом [тернарного оператора](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Operators/Conditional_operator).

### Синтаксис
```javascript
iif(condition, valueTrue, valueFalse)
```
### Параметры
- condition: boolean - условие, которое определяет возвращаемое значение;
- valueTrue: any - значение, возвращаемое в случае, если условие true;
- valueFalse: any - значение, возвращаемое в случае, если условие false. 

### Возвращаемое значение
any - одно из значений (valueTrue или valueFalse), в зависимости от результата логического условия.

### Пример
```javascript
var price = 5000;
var discount = iif(price > 1000, 0.2, 0.1);
return discount;
```

### Примечание
Функция предназначена для повышения читаемости кода и удобства. 
Аналогичные вычисления можно выполнить при помощи тернарного оператора.
```javascript
var price = 5000;
var discount = price > 1000 ? 0.2 : 0.1;
return discount;
```

## ifs
Функция вычисляет набор условий и возвращает первое значение, для которого условие истинно. Это аналог конструкции [switch](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Statements/switch), но позволяет записать логику в одной строке. Удобна для использования в выражениях, где требуется лаконичная форма ветвления.

Функция принимает четное количество аргументов: нечетные аргументы — условия (boolean), четные — возвращаемые значения (any). Функция возвращает первое значение, для которого условие истинно. Если ни одно из условий не истинно, рекомендуется использовать true в качестве последнего условия, чтобы задать значение по умолчанию.

### Синтаксис
```javascript
ifs(condition1, value1, condition2, value2, ..., conditionN, valueN)
```
### Параметры
- condition: boolean - условие, определяющее, будет ли возвращено соответствующее значение.
- value: any - значение, возвращаемое, если условие истинно.
### Возвращаемое значение
any - Первое значение, для которого условие истинно. Если ни одно условие не истинно, возвращается null.

### Пример
```javascript
var taxName = 'tax_10';
var rate = ifs( taxName == 'tax_10', 0.1, taxName == 'tax_20', 0.2, true, 0.05);
return rate;
```

### Примечание
Функция ifs является удобным инструментом для краткой записи условий, где стандартная конструкция switch занимает больше места и усложняет выражения. Аналогичные вычисления могут быть выполнены с помощью switch, но ifs позволяет сохранить код в более компактной форме

```javascript
var taxName = 'tax_10';
var rate = 0;
switch(taxName){
  case 'tax_10':
    rate = 0.1;
    break;
  case 'tax_20':
    rate = 0.2;
    break;
  default: 
    rate = 0.05;
    break;
}
return rate;
```

## isEmpty
Определяет является ли значение пустым. Проверка выполняется на основе стандартных 
правил JavaScript для определения "пустых" значений, таких как null, undefined, пустые строки, числа 0, объекты без свойств и т.д.

### Синтаксис
```javascript
isEmpty(value)
```
### Параметры
value: any - значение, которое требуется проверить.

### Возвращаемое значение
boolean - Возвращает true, если значение считается пустым, и false в противном случае.

### Пример
```javascript
var quantity = 0;
isEmpty(quantity);
```

### Примечание
Функция предназначена для повышения читаемости кода и удобства. В большинстве случаев такую проверку можно выполнить стандартными средствами JavaScript, например:

```javascript
var quantity = 0;
if (!quantity){
    return true;
}
else {
    return false;
}
```
Однако, использование isEmpty может сделать код более понятным и лаконичным.

## isNotEmpty
Определяет является ли значение заполненным. Проверка выполняется на основе стандартных 
правил JavaScript для определения "пустых" значений, таких как null, undefined, пустые строки, числа 0, объекты без свойств и т.д.

### Синтаксис
```javascript
isEmpty(value)
```
### Параметры
value: any - значение, которое требуется проверить.

### Возвращаемое значение
boolean - Возвращает true, если значение считается заполненным, и false в противном случае.

### Пример
```javascript
var quantity = 1;
isNotEmpty(quantity);
```

### Примечание
Функция предназначена для повышения читаемости кода и удобства. В большинстве случаев такую проверку можно выполнить стандартными средствами JavaScript, например:

```javascript
var quantity = 1;
if (quantity){
    return true;
}
else {
    return false;
}
```
Однако, использование isNotEmpty может сделать код более понятным и лаконичным.

## parseNumber
Преобразует строку в число.  
Если строка не может быть корректно интерпретирована как число, возвращается число ноль.

### Синтаксис
```javascript
parseNumber(inputString);
```
### Параметры
inputString: string — строка, которую необходимо преобразовать в число.
### Возвращаемое значение
number — числовое значение, полученное из строки, либо 0, если преобразование невозможно.
### Пример
```javascript
var n1 = parseNumber('8');
var n2 = parseNumber('БЛ');

// { n1: 8, n2: 0 }
return {n1, n2}; 
```

## round
Округляет число до указанного десятичного разряда. Выбирается ближайшее значение; если расстояние до двух значений одинаково, округление выполняется от нуля. Поэтому `round(1.5)` возвращает `2`, а `round(-1.5)` — `-2`.

Округление выполняется по десятичной записи переданного числа. Например, `round(1.005, 2)` возвращает `1.01`. Поддерживаются также числа в экспоненциальной форме: `round(1.25e-7, 8)` возвращает `1.3e-7`.

### Синтаксис
```javascript
round(value, digits = 0)
```

### Параметры
- value: number — число, которое необходимо округлить. Принимается только примитивное числовое значение; строки, `null`, логические значения и объекты, включая `new Number(...)`, не преобразуются в число.
- digits *(необязательный)*: number — целое число от -308 до 324. Положительное значение задаёт количество знаков после десятичной точки, отрицательное — разряд до неё: `-1` округляет до десятков, `-2` — до сотен. По умолчанию, в том числе при передаче `undefined`, используется 0 — округление до целого.

### Возвращаемое значение
number — округлённое число. Конечные нули не сохраняются: `round(1.2, 2)` возвращает число `1.2`. Для получения строки `'1.20'` используйте [formatNumber](#formatnumber) или [format](#format).

При допустимом `digits` значения `NaN`, `Infinity` и `-Infinity` возвращаются без изменения. Любой нулевой результат возвращается как положительный ноль.

Результат остаётся числом JavaScript с ограничениями IEEE 754. Функция не восстанавливает уже потерянные цифры и не делает последующие вычисления точной десятичной арифметикой; при переполнении результат может стать бесконечностью.

### Ошибки
- `TypeError` — если `value` не передан или `value` либо `digits` имеет нечисловой тип.
- `RangeError` — если числовой `digits` дробный, бесконечный, равен `NaN` или находится вне диапазона от -308 до 324.

Проверка аргументов выполняется и для значений `NaN` и бесконечностей.

### Примеры
```javascript
round(12.6);             // 13
round(1234.567, 2);      // 1234.57
round(1234.567, -2);     // 1200
round(1.005, 2);         // 1.01
round(-1.005, 2);        // -1.01
round(-1.5);            // -2
round(1.2, 2);           // 1.2
round(-0.004, 2);        // 0
round(NaN);              // NaN
round(Infinity);         // Infinity
```

Некорректные аргументы вызывают ошибку:
```javascript
round('1.25', 2);        // TypeError
round(1.25, '2');        // TypeError
round(1.25, 1.5);        // RangeError
round(1.25, 325);        // RangeError
```

## runWorkflow
Запускает процесс (workflow) на выполнение и возвращает результат после его завершения.

### Синтаксис
```javascript
var result = await runWorkflow(workflowName, resultStepName, parameters, timeout);
```
### Параметры
workflowName: string - имя процесса.
resultStepName: string - имя шага процесса, из которого необходимо извлечь данные.
*parameters (необязательный)*: [workflowParameter](workflowParameter.md)[] - массив параметров процесса.
*timeout (необязательный)*: число - таймаут в секундах. По умолчанию - 15 секунд.
### Возвращаемое значение
any - значение из указанного шага процесса.

### Пример
```javascript
var result = await runWorkflow('load_from_excel', 
                               'result', 
                               [{name: 'id', 
                                 dataType: 'integer', 
                                 value: $h.number}]);

return result;

```
