# Компонент `BsDetailsTableComponent`

Компонент предназначен для редактирования табличной части документа или справочника. Внутри используется [PrimeVue DataTable](https://v3.primevue.org/datatable/) с подключёнными механизмами выделения строки, сортировки и фильтрации по колонкам, изменения ширины и порядка колонок, постраничного вывода, а также встроенной колонкой номера строки и колонкой действий (удалить, копировать, переместить вверх/вниз, пересчитать). Тип элемента ввода в ячейке задаётся свойством `control` колонки и поддерживает текст, число, дату/время, флажок, переключатель, поле с маской и выбор объекта метаданных. В конструкторе форм компонент доступен под именем `bs-details-table`.

Типовые сценарии использования:

- табличная часть документа или справочника внутри вкладки `pv-tab-panel` формы редактирования;
- редактируемый список строк с зависимыми колонками (когда часть полей рассчитывается по событию `rowRecalculate`);
- табличный ввод с колонками разных типов (объектная ссылка, число с заданной точностью, дата, поле с маской);
- табличный ввод с условным редактированием/видимостью колонок (свойства `:disabled` и `:visible` колонки, вычисляемые по полям шапки).

## Props

- **header** (`DataObject`, обязательный) — текущий объект-шапка, в составе которого редактируется табличная часть. Передаётся в редакторы ячеек с выбором объекта метаданных (`BsObjectReferenceSelect`) — например, для контекстной фильтрации справочников по полям шапки. В форме-конструкторе типично задаётся как `:header = "data.header"`.
- **table** (`DataObjectDetailsTable`, обязательный) — модель табличной части. Содержит `kind`, `objectName`, `objectUid`, `name` (техническое имя таблицы), `title`, `uid`, признак модифицированности и массив строк `rows`. Если массив `rows` пуст, при монтировании компонент сам загрузит данные с сервера через `DataObjectsProvider.getDetailsTable`. В форме-конструкторе типично задаётся как `:table = "$t.<имя>"` (сокращение раскрывается в `data.tables.<имя>`).
- **columns** (`DetailsTableColumnViewModel[]`, обязательный) — описания колонок. В форме-конструкторе массив формируется автоматически из дочерних элементов `bs-details-table-column`. В программируемом компоненте передаётся явно. Каждая колонка описывается следующими полями:

  | Поле           | Тип       | Назначение                                                                                                                                                              |
  | -------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | `name`         | `string`  | Имя поля строки, отображаемого в колонке. Если имя оканчивается на `_display`, имя поля-значения вычисляется отбрасыванием суффикса (используется для редакторов-ссылок). |
  | `title`        | `string`  | Заголовок колонки.                                                                                                                                                      |
  | `control`      | `string`  | Тип редактора ячейки (см. таблицу ниже).                                                                                                                                |
  | `width`        | `string`  | Ширина колонки (`auto`, `120px`, `15rem` и т. п.).                                                                                                                       |
  | `sortable`     | `boolean` | Разрешена ли сортировка по колонке.                                                                                                                                     |
  | `sortField`    | `string`  | Имя поля строки, по которому ведётся сортировка (если отличается от `name`).                                                                                            |
  | `frozen`       | `boolean` | Колонка зафиксирована при горизонтальной прокрутке.                                                                                                                     |
  | `disabled`     | `boolean` | Колонка только для чтения (ячейки подсвечиваются серым, редактор не открывается).                                                                                       |
  | `visible`      | `boolean` | Видима ли колонка. Скрытые колонки не отображаются и не учитываются в выводе.                                                                                            |
  | `dataType`     | `string`  | UID типа данных для колонок-ссылок (`control = "dropdown"`).                                                                                                            |
  | `itemsSource`  | `string`  | Источник элементов для выпадающего списка.                                                                                                                              |
  | `pattern`      | `string`  | Регулярное выражение для колонок с маской (`control = "input-pattern"`). См. [`BsInputPattern`](bsInputPatternComponent.md).                                            |
  | `numberDigits` | `number`  | Количество знаков после запятой для числовых колонок (`control = "input-number"`).                                                                                       |
  | `hasFilter`    | `boolean` | Включает меню фильтра в шапке колонки.                                                                                                                                  |
  | `filterKind`   | `string`  | Тип значения фильтра колонки (см. таблицу ниже).                                                                                                                        |

  Допустимые значения `control` соответствуют редакторам ячейки:

  | `control`        | Редактор ячейки                                                                                                  |
  | ---------------- | ---------------------------------------------------------------------------------------------------------------- |
  | `input-text`     | [PrimeVue InputText](https://v3.primevue.org/inputtext/)                                                         |
  | `input-textarea` | [PrimeVue InputText](https://v3.primevue.org/inputtext/) (используется при многострочных полях шапки таблицы)    |
  | `input-pattern`  | [`BsInputPattern`](bsInputPatternComponent.md) с регулярным выражением из `pattern`                              |
  | `input-number`   | [PrimeVue InputNumber](https://v3.primevue.org/inputnumber/) с точностью `numberDigits`                          |
  | `input-checkbox` | [PrimeVue Checkbox](https://v3.primevue.org/checkbox/) (binary)                                                  |
  | `input-switch`   | [PrimeVue InputSwitch](https://v3.primevue.org/inputswitch/)                                                     |
  | `input-date`     | [PrimeVue Calendar](https://v3.primevue.org/calendar/) (только дата, формат `dd.mm.yy`)                          |
  | `input-datetime` | [PrimeVue Calendar](https://v3.primevue.org/calendar/) (дата и время)                                            |
  | `dropdown`       | `BsObjectReferenceSelect` — выбор объекта метаданных. Параметры берутся из `dataType` и `itemsSource` колонки.   |

  Допустимые значения `filterKind` определяют тип значения фильтра колонки:

  | `filterKind`      | Поведение фильтра                                                            |
  | ----------------- | ---------------------------------------------------------------------------- |
  | `number`          | Число, оператор по умолчанию — `EQUALS`, поддерживается оператор `AND`.       |
  | `string`          | Подстрока, оператор по умолчанию — `CONTAINS`, поддерживается оператор `AND`. |
  | `boolean`         | Тройной флажок (`TriStateCheckbox`), оператор `EQUALS`.                       |
  | `date`            | Дата, оператор по умолчанию — `DATE_IS`, поддерживается оператор `AND`.       |
  | `dateTime`        | Дата/время, оператор по умолчанию — `DATE_IS`, поддерживается оператор `AND`. |
  | `objectReference` | Точное равенство с выбранным значением (`EQUALS`).                            |
  | `select`          | Точное равенство со значением из `Dropdown` (значения уникальны из строк).    |
  | `multiSelect`     | Вхождение значения в выбранный список (`IN`).                                 |

- **paginator** (`boolean`, необязательный, по умолчанию `true`) — отображать ли постраничную навигацию внизу таблицы. По умолчанию выводится 100 строк на страницу, доступные размеры — `10/20/50/100/500`.
- **height** (`string`, необязательный) — высота таблицы. Принимает обычные CSS-значения (`300px`, `60vh`) либо специальное значение `stretch` — в этом режиме компонент через `ResizeObserver` и обработчик `resize` окна автоматически занимает всё свободное пространство по высоте до низа окна (с учётом высоты постраничной навигации, если она включена).
- **resizableColumns** (`boolean`, обязательный) — разрешать ли пользователю менять ширину колонок «потягиванием» их границы. При завершении изменения новая ширина сохраняется в соответствующем `DetailsTableColumnViewModel` через `column.setWidth(...)`.
- **reorderableColumns** (`boolean`, обязательный) — разрешать ли пользователю менять порядок колонок перетаскиванием их заголовков.
- **size** (`'normal' | 'compact' | 'small'`, необязательный, по умолчанию `'compact'`) — размер текста таблицы. К корневому элементу таблицы добавляется CSS-класс `bs-table-size-<size>`:

  | Значение `size` | Размер шрифта таблицы |
  | --------------- | --------------------- |
  | `normal`        | `1rem` (~14px)        |
  | `compact`       | `0.85rem` (~12px)     |
  | `small`         | `0.75rem` (~10.4px)   |

В таблице всегда присутствуют две служебные колонки, которые не описываются через `columns`:

- колонка `#` — порядковый номер строки в текущей сортировке (всегда зафиксирована);
- колонка действий — иконки «удалить», «копировать», «переместить вверх», «переместить вниз», «пересчитать».

## События

Компонент эмитит следующие события:

| Событие           | Аргументы                                                | Когда возникает                                                                                  |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `change`          | —                                                        | Любое изменение строки — редактирование ячейки, копирование/удаление, перемещение строки вверх/вниз. |
| `rowFieldChange`  | `columnName: string, tableUid: string, row: any`         | Завершено редактирование ячейки. Для колонок-ссылок (`_display`) в `columnName` передаётся имя поля-значения. |
| `tableChange`     | `tableName: string, tableUid: string`                    | Изменился набор строк — строка удалена или скопирована.                                          |
| `rowRecalculate`  | `tableName: string, tableUid: string, row: any`          | Пользователь нажал значок «пересчитать» в колонке действий.                                       |

В форме-конструкторе обработчики этих событий назначаются командами объекта (имена команд резолвятся через `handlers`, см. [Конструктор форм](formConstructor.md)). Конкретные имена обработчиков, ожидаемые рендерером, — `onRowFieldChange`, `onTableChange`, `onRowRecalculate`.

## Доступные методы

Компонент экспонирует через `defineExpose` метод `clearFilters()` — сбрасывает значения всех фильтров колонок к их исходным состояниям. Метод вызывается из родительского компонента по `ref`. В форме-конструкторе ссылка на компонент сохраняется в `formState` под именем, заданным свойством `name` (например, `name = "время"` → `formState.время`), и связан со стандартной командой `standard.clear_filters:<имя>`.

## Свойства по умолчанию в конструкторе форм

При добавлении компонента через визуальный конструктор форм (`FormElementBuilder.createDetailsTable`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию |
| --------------- | --------------------- |
| `ComponentName` | `bs-details-table`    |
| `CssClass`      | пусто                 |
| `Style`         | пусто                 |
| `:table`        | `data.tables.`        |

Остальные свойства (`:header`, `height`, `:resizableColumns`, `:reorderableColumns`, `size`, `paginator`, `name`) по умолчанию не заполняются — их следует задавать вручную. Конкретное имя табличной части (`$t.<имя>` или `data.tables.<имя>`) добавляется в значение `:table` при привязке к данным.

Колонки добавляются как дочерние элементы `bs-details-table-column` (`FormElementBuilder.createDetailsTableColumn`):

| Поле            | Значение по умолчанию       |
| --------------- | --------------------------- |
| `ComponentName` | `bs-details-table-column`   |
| `title`         | пусто                       |
| `name`          | пусто                       |
| `width`         | `auto`                      |
| `control`       | `input-text`                |

## Примеры использования

### Использование в шаблоне (программируемый компонент)

```html
<BsDetailsTableComponent
  :header="data.header"
  :table="data.tables.позиции"
  :columns="columns"
  height="stretch"
  :resizable-columns="true"
  :reorderable-columns="true"
  size="compact"
  @row-field-change="onRowFieldChange"
  @table-change="onTableChange"
  @row-recalculate="onRowRecalculate" />
```

### Использование в форме-конструкторе (JSON)

Типовая табличная часть с растянутой высотой, изменяемой шириной и порядком колонок (взято из формы редактирования объекта `operation.монтаж_площадка`, табличная часть «время»). Колонки описаны как дочерние элементы; в примере приведены две колонки — выпадающий список с фильтром по строке и числовая колонка с тремя знаками после запятой и условной видимостью:

  "componentName": "bs-details-table",

  "style": "",

    { "name": ":table", "value": "$t.время" },
    { "name": "height", "value": "stretch" },
    { "name": ":resizableColumns", "value": "true" },
    { "name": ":reorderableColumns", "value": "true" },
    { "name": "name", "value": "время" }
  ],
  "items": [
    {
      "id": "bs-details-table-column-сотрудник",
      "componentName": "bs-details-table-column",
      "properties": [
        { "name": "title", "value": "Сотрудник" },
        { "name": "name", "value": "сотрудник_display" },
        { "name": "width", "value": "250px" },
        { "name": "control", "value": "dropdown" },
        { "name": "dataType", "value": "c47d3835-48d8-427f-be89-e84c082575ef" },
        { "name": "frozen", "value": "true" },

        { "name": "sortField", "value": "сотрудник_display" },

      "id": "bs-details-table-column-кту_часы",

        { "name": "title", "value": "КТУ*∑" },
