# Компонент `InputText` / `pv-input-text`

Стандартное однострочное текстовое поле из библиотеки PrimeVue. В **BaSYS** применяется для ввода произвольных строковых значений в формах редактирования (поля шапки документа/справочника, реквизиты табличной части) и в шаблонах программируемых компонентов (поля ввода в диалогах, фильтрах, чатах). Полный список props, событий и слотов приведён в [PrimeVue 3 — InputText](https://v3.primevue.org/inputtext/).

## Доступность в BaSYS

- В конструкторе форм — под именем `pv-input-text` (реестр `ConstructorComponents`).
- В программируемых компонентах — под именем `InputText` (без регистрации, см. перечень в [Программируемые компоненты](programmableComponents.md)).

## Часто используемые в BaSYS props

- **vModel** — двусторонняя привязка к значению поля. В формах-конструкторах указывается путь в модели формы: `$h.<имя>` для полей шапки документа/справочника, `$r.<имя>` для полей строки табличной части (см. раздел [Привязки данных и события](formConstructor.md#привязки-данных-и-события) в `formConstructor.md`). В программируемых компонентах используется обычный `v-model`.
- **size** (`'small' | 'large'`) — размер поля. В типовых формах **BaSYS** используется `small`.
- **autocomplete** (`string`) — управление автозаполнением браузера. В **BaSYS** по умолчанию выставляется `off`, чтобы браузер не предлагал ранее введённые значения.
- **placeholder** (`string`) — подсказка внутри пустого поля. Применяется в диалогах программируемых компонентов (например, поле ввода нового сообщения в чате).
- **:disabled** (`boolean`) — отключение поля. В JSON-формах удобно задавать привязкой к выражению на основе `formState` (например, `!$h.is_user_author`), чтобы поле редактировалось только в определённой роли/состоянии.
- **:invalid** (`boolean`) — подсветка ошибки валидации. В программируемых компонентах привязывается к результату собственной проверки (`errors.<имя>`).
- **id** (`string`) — идентификатор `<input>`. В программируемых компонентах используется для связи с `<label for>` и для управления `autofocus`.

В обработчиках событий (`@Change`, `@Input` и т. п.) в формах-конструкторах задаётся имя команды объекта (см. раздел [Команды](formConstructor.md#команды) в `formConstructor.md`); в программируемых компонентах — обычный обработчик `@input="onInput"`.

## Свойства по умолчанию в конструкторе форм

При добавлении поля через визуальный конструктор форм (`FormElementBuilder.createInputText`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию |
| --------------- | --------------------- |
| `ComponentName` | `pv-input-text`       |
| `CssClass`      | `w-full`              |
| `Style`         | пусто                 |
| `vModel`        | пустая строка         |
| `size`          | `small`               |
| `autocomplete` | `off`                 |

При автоматическом построении формы редактирования через `EditFormBuilder` для строкового поля шапки/строки таблицы `vModel` заполняется как `$h.<имя>` (для шапки) либо `$r.<имя>` (для колонки табличной части).

## Примеры использования

### В программируемом компоненте (template)

Поле «Тема» в диалоге создания задачи (`operation.task.form.create_task.vue`). Связано с `v-model`, подсвечивается по результату валидации (`:invalid`), управляется `<label for>` и получает фокус при открытии диалога:

```html
<label for="topic" class="bs-required">Тема</label>
<InputText id="topic"
           v-model="topic"
           :invalid="errors.topic"
           autocomplete="off"
           autofocus
           size="small"
           class="w-full" />
```

Поле ввода нового сообщения в чате задачи (`operation.task.form.my_tasks_script.vue`) — рядом с кнопкой отправки, занимает всё доступное место строки за счёт `flex: 1` и подсказывает назначение через `placeholder`:

```html
<InputText v-model="newMessageText"
           placeholder="Введите сообщение..."
           autocomplete="off"
           :style="{ flex: '1' }" />
```

### В форме-конструкторе (JSON)

Минимальный вариант — поле «Комментарий» в форме редактирования тарифа (`operation.тарифы_дорожные.form.edit_QLItN2.json`). Привязано к полю шапки `комментарий` через сокращение `$h.`:

```json
{
  "Id": "pv-input-text-p0wIZs",
  "DataUid": "a495af2d-6724-0753-e335-e2f8290a6127",
  "ComponentName": "pv-input-text",
  "CssClass": "w-full",
  "Style": "",
  "Properties": [
    { "Name": "vModel", "Value": "$h.комментарий" },
    { "Name": "size", "Value": "small" }
  ],
  "Items": []
}
```

Поле «Тема» в форме редактирования задачи (`operation.task.form.edit_PM2RXN.json`). Доступно для редактирования только автору задачи — это выражено привязкой `:disabled` к выражению на основе `formState`:

```json
{
  "Id": "pv-input-text-4zUnCt",
  "DataUid": "a212f9bf-d77b-3342-cb78-f0ba1bdbdd39",
  "ComponentName": "pv-input-text",
  "CssClass": "w-full",
  "Style": "",
  "Properties": [
    { "Name": "vModel", "Value": "$h.topic" },
    { "Name": "size", "Value": "small" },
    { "Name": ":disabled", "Value": "!$h.is_user_author" }
  ],
  "Items": []
}
```
