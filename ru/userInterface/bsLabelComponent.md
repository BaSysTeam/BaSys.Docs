# Компонент `BsLabelComponent`

Компонент предназначен для вывода подписи (HTML-элемента `<label>`) к полю ввода или произвольному элементу формы. Поддерживает атрибут `for` (через свойство `labelFor`) для логической привязки к элементу ввода, а также признак обязательности, добавляющий стандартный CSS-класс `bs-required` (используется в **BaSYS** для визуального выделения обязательных полей, например, красной звёздочкой). В конструкторе форм компонент доступен под именем `bs-label`.

Типовые сценарии использования:

- подпись к отдельному полю ввода, расположенному рядом с ней (когда [`bs-form-field`](formConstructor.md) избыточен);
- заголовок группы элементов или раздела формы (например, «История изменений» над списком записей);
- подпись к элементам собственной верстки в программируемых компонентах.

## Props

- **text** (`string`, обязательный) — текст подписи.
- **labelFor** (`string`, необязательный) — значение HTML-атрибута `for`; идентификатор элемента, с которым связана подпись.
- **id** (`string`, необязательный) — идентификатор корневого DOM-элемента (`<label>`).
- **style** (`Record<string, any>`, необязательный) — inline-стиль корневого DOM-элемента.
- **cssClass** (`string`, необязательный) — дополнительный CSS-класс. К корневому элементу всегда добавляется базовый класс `bs-label`; значение `cssClass` мержится с ним.
- **required** (`boolean`, необязательный, по умолчанию `false`) — при значении `true` к корневому элементу добавляется CSS-класс `bs-required` (визуальный признак обязательного поля).

## Свойства по умолчанию в конструкторе форм

При добавлении компонента через визуальный конструктор форм (`FormElementBuilder.createLabel`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию |
| --------------- | --------------------- |
| `ComponentName` | `bs-label`            |
| `CssClass`      | `w-full`              |
| `Style`         | пусто                 |
| `text`          | пустая строка         |
| `labelFor`      | пустая строка         |

Значения `id`, `style`, `required` и собственный `cssClass` по умолчанию не заполняются — их следует задавать вручную при необходимости.

## Примеры использования

### Использование в шаблоне (программируемый компонент)

Подпись с признаком обязательности рядом с полем ввода:

```html
<BsLabelComponent text="Тема"
                  labelFor="topic-input"
                  :required="true" />
<InputText id="topic-input" v-model="topic" size="small" class="w-full" />
```

### Использование в форме-конструкторе (JSON)

Заголовок группы элементов над списком (взято из формы редактирования объекта `operation.штатное_расписание`):

```json
{
  "id": "bs-label-0zY3rv",
  "componentName": "bs-label",
  "cssClass": "ml-7 mt-1",
  "style": "",
  "properties": [
    { "name": "text", "value": "История изменений" },
    { "name": "labelFor", "value": "" }
  ],
  "items": []
}
```

Подпись обязательного поля с привязкой к идентификатору элемента ввода:

```json
{
  "id": "bs-label-required",
  "componentName": "bs-label",
  "cssClass": "w-full",
  "style": "",
  "properties": [
    { "name": "text", "value": "Ответственный" },
    { "name": "labelFor", "value": "responsible-input" },
    { "name": ":required", "value": "true" }
  ],
  "items": []
}
```
