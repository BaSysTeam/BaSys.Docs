# Компонент `BsPeriodSelector`

Компонент выбирает период: границы `dateStart` и `dateFinish` и периодичность. В шаблоне программируемого компонента доступен под именем `BsPeriodSelector` (см. [программируемые компоненты](programmableComponents.md)). Через визуальный [конструктор форм](formConstructor.md) не создаётся. Фильтры отчётов используют тот же компонент и передают только границы периода.

Типовые сценарии использования:

- период отчёта или фильтра в шаблоне программируемой формы;
- список только нужных периодичностей (`allowedPeriodKinds`);
- фиксированная периодичность без смены карандашом (`lockPeriodKind`): листать период стрелками и выбирать его в календаре можно.

## Props

- **dateStart** (`Date | null`, обязательный) — начало периода. Привязка `v-model:dateStart`.
- **dateFinish** (`Date | null`, обязательный) — конец периода. Привязка `v-model:dateFinish`.
- **periodKind** (`number`, необязательный, по умолчанию `1`) — заданная периодичность, число из таблицы ниже. По умолчанию «Год».
- **allowedPeriodKinds** (`number[]`, необязательный) — периодичности, которые видны в списке. Свойство не задано или передан пустой массив — в списке все шесть вариантов. Пустой набор раньше оставлял список пустым.
- **lockPeriodKind** (`boolean`, необязательный, по умолчанию `false`) — скрывает иконку карандаша: сменить периодичность нельзя. Листать период стрелками и выбирать его в календаре можно.

### Значения периодичности

В шаблоне программируемой формы перечисление `PeriodKinds` недоступно: в свойства передаются числа.

| Значение | Подпись            |
| -------- | ------------------ |
| `1`      | Год                |
| `2`      | Квартал            |
| `3`      | Месяц              |
| `4`      | День               |
| `5`      | Произвольный       |
| `6`      | Без ограничения    |

В выпадающем списке порядок всегда такой: «День», «Месяц», «Квартал», «Год», «Произвольный», «Без ограничения». В список попадают только значения из `allowedPeriodKinds`.

## События

- **`update:dateStart`** `(value: Date | null)` — изменилось начало периода (`v-model:dateStart`).
- **`update:dateFinish`** `(value: Date | null)` — изменился конец периода (`v-model:dateFinish`).
- **`change`** `({ dateStart, dateFinish, periodKind })` — изменились границы или периодичность. `periodKind` — число из таблицы выше.

## Поведение

- Карандаш открывает список периодичностей. Подпись периода открывает календарь текущей периодичности: год, квартал, месяц, день или две даты для «Произвольный».
- У «Без ограничения» карандаша нет, и список периодичностей открывает подпись периода. Стрелки отключены для «Произвольный» и «Без ограничения».
- Если текущая периодичность не входит в `allowedPeriodKinds`, она заменяется на `periodKind`, когда это значение разрешено, иначе на «Произвольный» (`5`), иначе на первый элемент переданного массива. Границы периода пересчитываются под новую периодичность. Для «Произвольный» введённые даты сохраняются.
- При `lockPeriodKind` карандаш скрыт, сменить периодичность нельзя. Стрелки и календарь по подписи периода остаются. Если при этом периодичность — «Без ограничения», подпись больше не открывает список.
- Свойства задаются в шаблоне программируемой формы. Фильтры отчётов эти свойства не передают. Ранее сохранённые формы без `allowedPeriodKinds` и `lockPeriodKind` открываются как раньше: в списке все шесть периодичностей, карандаш на месте.

## Свойства по умолчанию в конструкторе форм

Компонент не создаётся через визуальный конструктор; добавляется вручную или из шаблонов программируемых компонентов.

## Примеры использования

### Использование в шаблоне (программируемый компонент)

Привязка границ и периодичности:

```html
<BsPeriodSelector v-model:dateStart="dateStart"
                  v-model:dateFinish="dateFinish"
                  :periodKind="periodKind"
                  @change="onPeriodChange" />
```

Только месяц и квартал (`3` и `2`):

```html
<BsPeriodSelector v-model:dateStart="dateStart"
                  v-model:dateFinish="dateFinish"
                  :periodKind="3"
                  :allowedPeriodKinds="[3, 2]"
                  @change="onPeriodChange" />
```

Периодичность зафиксирована на месяце: карандаш скрыт, стрелки и календарь доступны.

```html
<BsPeriodSelector v-model:dateStart="dateStart"
                  v-model:dateFinish="dateFinish"
                  :periodKind="3"
                  lockPeriodKind />
```
