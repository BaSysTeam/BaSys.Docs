# Компонент `Divider` / `pv-divider`

Стандартный разделитель из библиотеки PrimeVue. В **BaSYS** применяется для визуального отделения логических блоков формы (заголовок и тулбар от таблицы, тулбар от полей шапки, секции внутри программируемых компонентов и шаблонов узлов в дереве задач). Полный список props, событий и слотов приведён в [PrimeVue 3 — Divider](https://v3.primevue.org/divider/).

## Доступность в BaSYS

- В конструкторе форм — под именем `pv-divider` (реестр `ConstructorComponents`).
- В программируемых компонентах — под именем `Divider` (без регистрации, см. перечень в [Программируемые компоненты](programmableComponents.md)).

## Часто используемые в BaSYS props

В типовых формах **BaSYS** разделитель используется со значениями по умолчанию: горизонтальный, сплошной, без содержимого. Кастомизация ограничивается отступами через свойство `style` (или `Style` в JSON):

- **style** (`string`) — inline-стиль корневого DOM-элемента. Используется почти исключительно для управления вертикальными отступами (`margin: 5px;` — значение из конструктора форм, `margin: 0;` — плотная компоновка в программируемых компонентах).
- **cssClass** (`string`) — дополнительный CSS-класс корневого элемента.

Если требуется нестандартное поведение разделителя, доступны базовые props PrimeVue (значения и оформление см. в [официальной документации](https://v3.primevue.org/divider/)):

- **layout** (`'horizontal' | 'vertical'`) — ориентация. По умолчанию `horizontal`.
- **type** (`'solid' | 'dotted' | 'dashed'`) — стиль линии. По умолчанию `solid`.
- **align** (`'left' | 'center' | 'right' | 'top' | 'bottom'`) — выравнивание содержимого (если разделитель используется со слотом).

Разделитель не имеет собственных событий и привязок к данным — обработчики `@Click`/`@Change` к нему не применяются.

## Свойства по умолчанию в конструкторе форм

При добавлении разделителя через визуальный конструктор форм (`FormElementBuilder.createDivider`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию |
| --------------- | --------------------- |
| `ComponentName` | `pv-divider`          |
| `CssClass`      | пусто                 |
| `Style`         | `margin: 5px;`        |
| `Properties`    | пусто                 |

Дополнительно разделитель добавляется автоматически в формы, создаваемые помощниками `ListFormBuilder` и `EditFormBuilder` (см. раздел [Быстрое создание формы списка и формы редактирования](formConstructor.md#быстрое-создание-формы-списка-и-формы-редактирования) в `formConstructor.md`) — между тулбаром и таблицей в форме списка и между панелью кнопок и полями шапки в форме редактирования.

## Примеры использования

### В программируемом компоненте (template)

Разделитель с нулевым отступом отделяет тулбар от области с деревом задач (`operation.task.form.tasks_tree.vue`):

```html
<div class="grid">
  <div class="col">
    <Divider style="margin:0;"></Divider>
  </div>
</div>
```

Внутри шаблона узла дерева — небольшой разделитель с отступом `5px` между ФИО ответственного и темой задачи (`operation.task.form.tasks_tree.vue`):

```html
<div>
  <span>{{ slotProps.node.responsible }}</span>
</div>

<Divider style="margin: 5px;"></Divider>

<div class="text-sm">
  <span>{{ slotProps.node.topic }}</span>
</div>
```

Разделители в диалоге личных задач (`operation.task.form.my_tasks_script.vue`) — без атрибутов, со значениями по умолчанию:

```html
<Divider />
```

### В форме-конструкторе (JSON)

Разделитель между панелью команд формы списка и таблицей `bs-table-view` (`operation.task.form.list_veNfSv.json`) — со значением `Style`, выставленным конструктором по умолчанию:

```json
{
  "Id": "pv-divider-To8gti",
  "ComponentName": "pv-divider",
  "CssClass": "",
  "Style": "margin: 5px",
  "Properties": [],
  "Items": []
}
```

Тот же шаблон используется в форме редактирования между панелью кнопок и полями шапки (`operation.task.form.edit_PM2RXN.json`):

```json
{
  "Id": "pv-divider-xSb5hO",
  "ComponentName": "pv-divider",
  "CssClass": "",
  "Style": "margin: 5px",
  "Properties": [],
  "Items": []
}
```
