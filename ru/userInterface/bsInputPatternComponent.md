# Компонент `BsInputPattern`

Компонент предназначен для однострочного ввода текста с проверкой по регулярному выражению. На каждый ввод значение сверяется с указанным шаблоном; если значение невалидно — поле подсвечивается красным (`bs-p-invalid`) и атрибут `invalid` передаётся в нижележащий [PrimeVue InputText](https://v3.primevue.org/inputtext/). При выходе по `Tab`, `Enter` или потере фокуса (`blur`) невалидное значение откатывается до последнего корректного, что не даёт «сломать» привязанное поле формы. В конструкторе форм компонент доступен под именем `bs-input-pattern`.

Типовые сценарии использования:

- ввод значений со строгим форматом (артикул, табельный номер, номер этажа с допустимыми буквенными обозначениями и т. п.);
- ввод по комбинированному списку допустимых значений, который проще описать регулярным выражением, чем выпадающим списком;
- ячейка табличной части (`bs-details-table-column` с `control = "input-pattern"`) для столбцов со специфическим форматом ввода.

## Props

- **modelValue** (`string`, необязательный) — текущее значение поля. Двусторонняя привязка через `v-model` (в форме-конструкторе — свойство `vModel`).
- **pattern** (`string`, необязательный) — регулярное выражение, по которому проверяется значение. Поддерживаются два варианта записи:
  - литерал JavaScript-регулярки — `/<тело>/<флаги>` (например, `/^[A-Z]{3}-\d{4}$/i`); флаг `g` принудительно убирается;
  - «голое» выражение — без обрамляющих слешей; компилируется с флагом `u` (`^(?:\d+|НС|БС)$`).

  Если выражение пустое или некорректное (не компилируется), проверка фактически отключается и любое значение считается валидным.
- **size** (`'small' | 'large'`, необязательный, по умолчанию `'small'`) — размер поля; передаётся в `InputText` PrimeVue.
- **id** (`string`, необязательный) — идентификатор корневого DOM-элемента (`<input>`).
- **inputClass** (`string`, необязательный) — дополнительный CSS-класс поля ввода. К полю всегда добавляется `bs-p-invalid`, когда значение не проходит проверку; `inputClass` мержится с ним.
- **inputStyle** (`string`, необязательный) — inline-стиль поля ввода.

Компонент эмитит единственное событие `update:modelValue` (обеспечивает работу `v-model`). Эмит происходит и при невалидном промежуточном вводе, и при откате к последнему корректному значению.

### Логика проверки

| Событие        | Поведение                                                                                                       |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| `input`        | Значение сверяется с `pattern`. При несоответствии поле помечается невалидным, но ввод не блокируется.          |
| `keydown` (`Tab`/`Enter`) | При невалидном значении нажатие отменяется (`preventDefault`), значение откатывается до последнего валидного. |
| `blur`         | При невалидном значении выполняется откат до последнего валидного.                                              |
| Пустая строка  | Считается валидной независимо от `pattern`.                                                                     |

## Свойства по умолчанию в конструкторе форм

При добавлении компонента через визуальный конструктор форм (`FormElementBuilder.createInputPattern`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию |
| --------------- | --------------------- |
| `ComponentName` | `bs-input-pattern`    |
| `CssClass`      | `w-full`              |
| `Style`         | пусто                 |
| `vModel`        | пустая строка         |
| `size`          | `small`               |
| `pattern`       | пустая строка         |

Значения `id`, собственный `inputClass` и `inputStyle` по умолчанию не заполняются — их следует задавать вручную при необходимости.

## Примеры использования

### Использование в шаблоне (программируемый компонент)

Свободный ввод без проверки (фактически — обычный `InputText`):

```html
<BsInputPattern id="test-input"
                inputClass="w-full"
                v-model="stringValue1" />
```

Ввод значения, ограниченного регулярным выражением (число, либо одна из аббревиатур `НС`/`БС` — например, для обозначения этажа в системе диспетчеризации лифтов):

```html
<BsInputPattern id="test-input"
                inputClass="w-full"
                pattern="^(?:\d+|НС|БС)$"
                v-model="stringValue2" />
```

### Использование в форме-конструкторе (JSON)

Поле шапки с фиксированным форматом артикула — большие латинские буквы и цифры через дефис:

```json
{
  "id": "bs-input-pattern-article",
  "componentName": "bs-input-pattern",
  "cssClass": "w-full",
  "style": "",
  "properties": [
    { "name": "vModel", "value": "$h.article" },
    { "name": "pattern", "value": "^[A-Z]{3}-\\d{4}$" },
    { "name": "size", "value": "small" }
  ],
  "items": []
}
```

Динамический шаблон, вычисляемый по другому полю шапки (например, шаблон формируется в `onInitializedScript` или в computed-свойстве):

```json
{
  "id": "bs-input-pattern-code",
  "componentName": "bs-input-pattern",
  "cssClass": "w-full",
  "style": "",
  "properties": [
    { "name": "vModel", "value": "$h.code" },
    { "name": ":pattern", "value": "data.header.code_pattern" },
    { "name": "size", "value": "small" }
  ],
  "items": []
}
```

### Использование в колонке табличной части

В колонке `bs-details-table-column` ввод с проверкой по шаблону включается значением `control = "input-pattern"`; при этом регулярное выражение задаётся свойством `pattern` колонки:

```json
{
  "id": "bs-details-table-column-floor",
  "componentName": "bs-details-table-column",
  "properties": [
    { "name": "title", "value": "Этаж" },
    { "name": "name", "value": "floor" },
    { "name": "width", "value": "auto" },
    { "name": "control", "value": "input-pattern" },
    { "name": "pattern", "value": "^(?:\\d+|НС|БС)$" }
  ],
  "items": []
}
```
