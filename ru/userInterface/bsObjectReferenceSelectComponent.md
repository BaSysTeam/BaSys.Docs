# Компонент `BsObjectReferenceSelect`

Компонент представляет собой выпадающий список, привязанный к ссылке на объект метаданных (документ, справочник, перечисление и т. п.). Реализован на базе [PrimeVue Dropdown](https://v3.primevue.org/dropdown/) с включёнными фильтром и виртуальным скроллингом. Коллекцию элементов компонент получает либо стандартным запросом к платформенному API (`/api/app/v1/SelectItems` для указанного типа данных), либо вычислением пользовательского скрипта `itemsSource`. В конструкторе форм компонент доступен под именем `bs-object-reference-select`. Платформенные построители форм (`EditFormBuilder`, `DetailsTableBuilder`) автоматически выбирают этот компонент для полей-ссылок (см. [конструктор форм](formConstructor.md)).

Типовые сценарии использования:

- ввод значения поля шапки или строки таблицы, имеющего тип «ссылка на объект метаданных» (документ, справочник, перечисление);
- ограничение допустимых значений выпадающего списка скриптом `itemsSource` (например, фильтрация справочника по другому полю шапки);
- редактирование статуса или перечисления — выбор из заранее определённого набора значений.

## Props

- **dataType** (`string`, обязательный) — UID типа данных метаданных, к которому относится ссылка. Используется и для получения коллекции по умолчанию (через стандартный API), и для подгрузки представления уже выбранного значения по `modelValue`.
- **modelValue** (`any`, необязательный) — текущее выбранное значение (`v-model`). Хранится «как есть» (как правило — идентификатор записи).
- **itemsSource** (`string`, необязательный) — JS-выражение, возвращающее коллекцию элементов выбора. Выполняется через `ExpressionEvaluator`; в области видимости доступны переменные `header` (шапка формы) и `currentRow` (текущая строка таблицы), а также хелперы скриптового контекста (`from`, `iif`, `isEmpty` и др.). Результатом может быть массив объектов `{ value, text }` либо `DataTable` — в этом случае используются его строки. При заполненном `itemsSource` коллекция автоматически перезапрашивается при глубоком изменении `header`, что удобно для зависимых выпадающих списков.
- **text** (`string`, необязательный) — отображаемый текст уже выбранного значения. Если указан, элемент с парой `{ value: modelValue, text }` добавляется в коллекцию сразу при монтировании — это позволяет показать выбранное значение без обращения к серверу. Обычно используется в паре с парным полем-«представлением», например `:text="$h.<поле>_display"`.
- **showClear** (`boolean`, необязательный, по умолчанию `true`) — отображать кнопку «очистить» в правой части поля.
- **disabled** (`boolean`, необязательный) — блокирует поле ввода и выпадающий список.
- **id** (`string`, необязательный) — идентификатор DOM-элемента (передаётся в нижележащий `Dropdown`).
- **class** (`string`, необязательный) — CSS-класс. В конструкторе форм передаётся через `cssClass`.
- **style** (`string`, необязательный) — inline-стиль корневого элемента.
- **inputStyle** (`any`, необязательный) — inline-стиль для внутреннего поля ввода `Dropdown`.
- **header** (`any`, необязательный) — объект шапки формы; передаётся в контекст вычисления `itemsSource`. В форме-конструкторе должен быть явно привязан выражением `:header="data.header"` — иначе ссылки на поля шапки (`$h.*`) в `itemsSource` не разрешатся. Платформенные построители (`EditFormBuilder`, `DetailsTableBuilder`) добавляют эту привязку автоматически.
- **currentRow** (`any`, необязательный) — текущая строка таблицы; передаётся в контекст вычисления `itemsSource`. Для полей внутри табличной части привязывается выражением `:currentRow="data.currentRow"` (по той же причине, что и `header`).
- **appendTo** (`string`, необязательный) — куда монтировать выпадающую панель (`appendTo` PrimeVue Dropdown), например `body`. Используется, когда поле находится внутри контейнера со скроллом или `overflow: hidden`.

## События

- **`update:modelValue`** `(value: any)` — выбрано новое значение (используется при `v-model` / `vModel`).
- **`selected`** `(item)` — выбран элемент списка; передаётся полный объект `{ value, text, … }`. Удобно для синхронного заполнения парного «display»-поля.

## Поведение

- Коллекция элементов запрашивается лениво — при первом открытии выпадающего списка (если ранее не было загружено более одного элемента) либо при изменении `dataType` / `itemsSource`.
- Если в загруженной коллекции отсутствует текущее значение (`modelValue`), значение сбрасывается в `null`, а наверх отправляется `update:modelValue`.
- Если коллекция пуста или не содержит текущее значение, дополнительно выполняется запрос одиночного элемента по `dataType` + `modelValue`, чтобы отобразить выбранное значение без полной загрузки списка.
- При заполненном `itemsSource` отслеживается глубокое изменение `header` — это позволяет строить зависимые списки (например, «договор» зависит от «контрагента»).

## Свойства по умолчанию в конструкторе форм

При добавлении компонента через визуальный конструктор форм (`FormElementBuilder.createObjectReferenceSelect`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию          |
| --------------- | ------------------------------ |
| `ComponentName` | `bs-object-reference-select`   |
| `CssClass`      | `w-full`                       |
| `Style`         | пусто                          |
| `vModel`        | пустая строка                  |
| `:text`         | пустая строка                  |
| `dataType`      | пустая строка                  |
| `itemsSource`   | пустая строка                  |

Значения `id`, `style`, `inputStyle`, `showClear`, `disabled`, `appendTo` по умолчанию не заполняются — их следует задавать вручную при необходимости. Свойства `:header` и `:currentRow` в результат `createObjectReferenceSelect` не попадают; их добавляют платформенные построители форм при автогенерации полей, а при ручном размещении компонента их нужно прописать (см. пример с `itemsSource` ниже).

## Примеры использования

### Использование в шаблоне (программируемый компонент)

Выбор справочника с лениво подгружаемой коллекцией и обработкой выбора:

```html
<BsObjectReferenceSelect :dataType="personTypeUid"
                         v-model="responsible"
                         class="w-full"
                         appendTo="body"
                         @selected="onResponsibleSelected" />
```

### Использование в форме-конструкторе (JSON)

Типовое поле «Ответственный» из формы редактирования объекта `operation.task` (минимальный набор свойств):

```json
{
  "id": "bs-object-reference-select-G11qJn",
  "dataUid": "44ff22fe-7fdc-8d14-cbc4-26f6b38816b3",
  "componentName": "bs-object-reference-select",
  "cssClass": "",
  "style": "",
  "properties": [
    { "name": "vModel", "value": "$h.responsible" },
    { "name": "size", "value": "small" },
    { "name": "dataType", "value": "30fa0620-3db1-43e2-a700-b6295739bbb6" }
  ],
  "items": []
}
```

Поле «Юридическое лицо» с предзаполненным представлением (`:text`) и условной блокировкой (`:disabled`) — из формы редактирования `operation.проект_договора`:

```json
{
  "id": "bs-object-reference-select-oL7suj",
  "dataUid": "bb909905-2e3d-eee0-8c70-fe74b106d3c8",
  "componentName": "bs-object-reference-select",
  "cssClass": "",
  "style": "",
  "properties": [
    { "name": "vModel", "value": "$h.юр_лицо" },
    { "name": ":text", "value": "$h.юр_лицо_display" },
    { "name": "size", "value": "small" },
    { "name": "dataType", "value": "01ef2eff-8bd1-498a-9aeb-52aa9598fc35" },
    { "name": ":disabled", "value": "$h.edit_disabled" }
  ],
  "items": []
}
```

Поле «Шифр КЖ» с фильтрацией коллекции по полю шапки `проект` через скрипт `itemsSource` — из формы редактирования `operation.заявка_площадки_с`. Привязка `:header="data.header"` обязательна: без неё ссылка `$h.проект` внутри `itemsSource` не разрешится и список окажется пустым.

```json
{
  "id": "bs-object-reference-select-shifrKj",
  "componentName": "bs-object-reference-select",
  "cssClass": "",
  "style": "",
  "properties": [
    { "name": "vModel", "value": "$h.шифр_кж" },
    { "name": "size", "value": "small" },
    { "name": "dataType", "value": "9838686b-9186-452e-b98c-3dfc4568d5b9" },
    {
      "name": "itemsSource",
      "value": "var project = $h.проект;\nvar t1 = await from('catalog.шифр_кж')\n  .where('проект = @project')\n  .parameter('project', project, 11)\n  .select(['id as value, title as text'])\n  .query();\n\nreturn t1;"
    },
    { "name": ":header", "value": "data.header" }
  ],
  "items": []
}
```
