# Компонент `BsViewTitle`

Компонент предназначен для отображения заголовка страницы. Поддерживает вывод индикатора ожидания и признака модифицированности данных.

## Props

- **title** (`string`, обязательный) — текст заголовка, отображаемый в компоненте.
- **isWaiting** (`boolean`, необязательный) — при значении `true` отображается индикатор ожидания (например, загрузки данных).
- **isModified** (`boolean`, необязательный) — при значении `true` отображается признак модифицированности (например, несохранённых изменений).

## Пример использования

```html
<BsViewTitle :title="title" :isWaiting="isWaiting" :isModified="isModified" />
```
