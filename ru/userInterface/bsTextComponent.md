# Компонент `BsTextComponent`

Компонент предназначен для отображения произвольного текстового блока. В отличие от обычной HTML-разметки, компонент поддерживает семантическую раскраску текста (`severity`) по аналогии с компонентами [PrimeVue 3](https://v3.primevue.org/), а также произвольную кастомизацию через CSS-класс и inline-стиль. В конструкторе форм компонент доступен под именем `bs-text`.

Типовые сценарии использования:

- подписи и заголовки внутри панели инструментов (`pv-toolbar`) — текст размещается в слоте `start` или `end`;
- информационные сообщения и подсказки на форме;
- статусы и метки в шаблонах программируемых компонентов (например, в ячейках дерева или таблицы).

## Props

- **text** (`string`, обязательный) — текст, отображаемый в компоненте.
- **id** (`string`, необязательный) — идентификатор корневого DOM-элемента.
- **style** (`Record<string, any>`, необязательный) — inline-стиль корневого DOM-элемента.
- **cssClass** (`string`, необязательный) — дополнительный CSS-класс корневого DOM-элемента.
- **severity** (`'primary' | 'secondary' | 'success' | 'info' | 'warning' | 'danger' | 'contrast'`, необязательный) — семантический цвет текста. Соответствует значениям `severity` компонента [PrimeVue Tag](https://v3.primevue.org/tag/) и автоматически добавляет один из следующих CSS-классов:

| Значение `severity` | CSS-класс       |
| ------------------- | --------------- |
| `primary`           | `text-primary`  |
| `secondary`         | `text-gray-500` |
| `success`           | `text-green-600`|
| `info`              | `text-blue-500` |
| `warning`           | `text-yellow-600`|
| `danger`            | `text-red-600`  |
| `contrast`          | `text-gray-900` |

## Свойства по умолчанию в конструкторе форм

При добавлении компонента через визуальный конструктор форм (`FormElementBuilder.createText`) создаётся `FormElement` со следующими значениями:

| Поле            | Значение по умолчанию                |
| --------------- | ------------------------------------ |
| `ComponentName` | `bs-text`                            |
| `CssClass`      | `w-full`                             |
| `Style`         | пусто                                |
| `text`          | пустая строка                        |
| `slot`          | не задаётся; добавляется, если компонент добавлен в слот родителя (например, `start`/`end` панели инструментов) |

Значения `severity`, `id` и собственный `style` по умолчанию не заполняются — их следует задавать вручную при необходимости.

## Примеры использования

### Использование в шаблоне (программируемый компонент)

Простой текст без семантической раскраски:

```html
<BsTextComponent text="Нет замечаний для согласования"
                 cssClass="w-full text-center"
                 :style="{ fontSize: '2rem', color: 'red' }" />
```

### Использование в форме-конструкторе (JSON)

Подпись в слоте `end` панели инструментов (типовой сценарий — заголовок таблицы или табличной части):

```json
{
  "id": "bs-text-sQnSOG",
  "componentName": "bs-text",
  "cssClass": "w-full",
  "style": "",
  "properties": [
    { "name": "text", "value": "Мои задачи" },
    { "name": "slot", "value": "end" }
  ],
  "items": []
}
```

Крупное информационное сообщение в колонке с условным рендерингом:

```json
{
  "id": "bs-text-N90uhh",
  "componentName": "bs-text",
  "cssClass": "w-full text-center",
  "style": "font-size: 2rem; color: red;",
  "properties": [
    { "name": "text", "value": "Нет замечаний для согласования" }
  ],
  "items": []
}
```

Текст с семантической раскраской через `severity`:

```json
{
  "id": "bs-text-status",
  "componentName": "bs-text",
  "cssClass": "",
  "style": "",
  "properties": [
    { "name": ":text", "value": "$h.status_title" },
    { "name": "severity", "value": "success" }
  ],
  "items": []
}
```
