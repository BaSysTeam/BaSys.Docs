# Программируемые компоненты

Программируемые компоненты используются для реализации сложных пользовательских интерфейсов, 
которые невозможно создать с помощью автоматических форм и конструктора форм. Они разрабатываются на базе фреймворка Vue.js 3 
с использованием Options API и библиотеки компонентов PrimeVue 3.

Такие компоненты динамически встраиваются в интерфейс системы BaSYS и могут использовать как стандартные компоненты PrimeVue 3, 
так и некоторые внутренние компоненты BaSYS. Перечень доступных компонентов приведён ниже.

Если требуется создать интерфейсы, не связанные с основным интерфейсом приложения **BaSYS** — например, использующие другие фреймворки, библиотеки или дизайн-системы — рекомендуется использовать механизм UI-плагинов либо реализовать внешнее frontend-приложение, взаимодействующее с **BaSYS** через API.

## Создание программируемых компонентов

Чтобы в объекте метаданных стало доступно использование программируемых компонентов, необходимо установить флаг **Использует формы** в виде метаданных, к которому относится данный объект. После установки флага в объекте метаданных становится доступен раздел **Формы**.

Для добавления нового программируемого компонента откройте раздел **Формы** и выберите в подменю **Добавить** пункт **Программируемый компонент**. После этого откроется форма редактирования программируемого компонента.


В форме редактирования программируемого компонента представлены несколько вкладок:

- **Скрипт** — здесь задаётся скрипт компонента с использованием Options API.
- **Шаблон** — на этой вкладке указывается шаблон (template) компонента.
- **Дочерние компоненты** — позволяет подключать другие программируемые компоненты для использования внутри текущего.
- **Основные** — содержит общую информацию о компоненте. Особое внимание следует уделить полю **Имя**, так как по нему компонент может быть подключён и повторно использован в других программируемых компонентах.

Программируемый компонент создаётся с минимально преднастроенными скриптом и шаблоном. Благодаря этому он сразу работоспособен, что упрощает начало разработки. Разработчик сам решает, использовать ли эти заготовки или начать с чистого листа.

## Использование внешних ресурсов

В некоторых случаях для решения задач требуется подключение внешних скриптов и стилей. В системе **BaSYS** это реализовано на уровне объекта метаданных. Если для объектов определённого вида метаданных установлен флаг **Использует формы**, становится доступен раздел **Внешние ресурсы**, где можно указать ссылки на скрипты или стили, размещённые в CDN.

Эти ресурсы будут динамически внедряться в `<head>` страницы приложения при отрисовке форм соответствующего объекта. Порядок подключения соответствует порядку, заданному в разделе **Внешние ресурсы**, и в некоторых случаях может иметь значение. Подключённые ресурсы автоматически становятся доступными и в программируемых компонентах.

Следует учитывать, что динамически подключаемые зависимости могут конфликтовать со скриптами и стилями самого приложения **BaSYS**, что может привести к ошибкам. В таких случаях рекомендуется использовать UI-плагины или внешние frontend-приложения вместо программируемых компонентов.
